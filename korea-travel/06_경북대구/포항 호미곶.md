# 포항 호미곶

| 항목 | 내용 |
|---|---|
| 소재지 | 경북 포항시 남구 호미곶면 해맞이로 136 (해맞이광장 일대) |
| 분류 | 해안·일출 |
| 추천 시기 | 새해 일출 |
| 운영·요금 | 해맞이광장 무료·무료주차(새천년기념관만 유료). 국립등대박물관 09:00~18:00(입장 17:30), 월요일 휴관, 무료 (2026-10 기준, 공식 확인 필요) |
| 예약 | 미확인(공식 확인 필요) |

## 볼거리
- 상생의 손(바다·육지 두 청동 조형물)
- 해맞이 광장
- 국립등대박물관, 새천년기념관

## 계절별 포인트
- 겨울: 호미곶한민족해맞이축전 12/31~1/1 (제28회, 2026-01 약 5만 명 보도). 올해 말 일정 미확인.

## 가는 법
- 포항역·버스터미널에서 9000번 버스 '호미곶광장' 하차(블로그 기준, 시간표 확인). 새해 일출 땐 주변 극심한 정체 보도.

## 주변 연계 코스
- 호미반도 해안둘레길 (경북문화관광공사 12월 여행지 선정)

## 팁
- 새해 일출 인파가 매우 많음. 이른 도착, 대중교통 권장.
