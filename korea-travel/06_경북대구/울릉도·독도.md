# 울릉도·독도

| 항목 | 내용 |
|---|---|
| 소재지 | 경북 울릉군 (독도는 울릉군 독도리) |
| 분류 | 섬 |
| 추천 시기 | 5~9월 (겨울엔 결항 잦음) |
| 운영·요금 | 도동→독도 성인 최저 6만원은 시간표 사이트 참고치, 포항 울릉크루즈 일반실 편도 8만원(2026-03 보도)은 지원사업 관련. 요금 자료별 상이, 공식 확인 필요 |
| 예약 | 여객선 예약 필수 수준. 통합 안내 ferry.ulleung.go.kr (직접 접속 못함) |

## 볼거리
- 성인봉(해발 984m)
- 도동~저동 행남해안산책로(2.8km, 2024 보수 후 재개통. 교량 구간 통행 상태 확인)
- 독도(울릉도에서 별도 배편, 기상 나쁘면 접안 못 하고 선회관람)

## 계절별 포인트
- 여름: 성수기 좌석 확보 어려움
- 겨울: 운휴 잦음

## 가는 법
- 육지 출발항: 강릉, 묵호, 후포, 포항. 2026-08 보도에 후포~울릉 여객선 중단, 엘도라도호 장기 고장이 있어 최신 운항 확인 필수.

## 주변 연계 코스
- 미확인(섬 내 일주 코스는 공식 확인 필요)

## 팁
- 일정 여유 필수. 성인봉 입산 조건·예약은 미확인(울릉군 문의).
