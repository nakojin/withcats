# 안동 하회마을

| 항목 | 내용 |
|---|---|
| 소재지 | 경북 안동시 풍천면 전서로 186 (검색 자료 기준) |
| 분류 | 유네스코 세계유산(2010) |
| 추천 시기 | 봄·가을 (안동국제탈춤페스티벌은 2026년 9/24~10/4 개최, 종료) |
| 운영·요금 | 어른 5,000원/청소년·군경 2,500원/어린이 1,500원(자료 일치). 하절기(4~9월) 09:00~18:00, 동절기(10~3월) 09:00~17:00, 입장마감은 자료별 상이. 연중무휴 안내 (2026-10 기준, 공식 확인 필요) |
| 예약 | 입장 예약 여부 미확인. 하회선유줄불놀이는 사전 예약제, 1만원(2026 보도) |

## 볼거리
- 한옥 마을(평지 흙길, 한 바퀴 약 2시간)
- 부용대
- 하회별신굿탈놀이(상설공연 요일·시간은 미확인, 2019~2020년 기사는 오후 2시)

## 계절별 포인트
- 가을: 탈춤페스티벌 시기
- 여름: 그늘 적어 더위 유의

## 가는 법
- 주차장 무료, 매표 후 무료 셔틀버스로 마을 입구 이동. 마을 내부 외부 차량 제한(2021 기사, 현행 확인 필요). 대중교통 노선은 미확인.

## 주변 연계 코스
- 병산서원, 월영교, 찜닭골목 (블로그 소개, 보조 자료)

## 팁
- 공연 일정은 안동시·보존회에 사전 확인.
