# 영주 부석사

| 항목 | 내용 |
|---|---|
| 소재지 | 경북 영주시 부석면 부석사로 345 |
| 분류 | 산사(유네스코 산사, 2018) |
| 추천 시기 | 가을(4월 벚꽃 보도도 있음) |
| 운영·요금 | 관람료 무료(2023-05부터 폐지 보도). 관람시간 미확인. 입구 공영주차 승용차 약 3,000원은 후기 기준(공식 확인 필요) |
| 예약 | 미확인(일반적으로 불필요하나 공식 확인 필요) |

## 볼거리
- 무량수전(배흘림기둥), 무량수전 앞 석등(국보 제17호)
- 소백산 능선 조망
- 국보 5건·보물 9건 보유 (여행 매체 소개)

## 계절별 포인트
- 가을: 단풍·조망
- 겨울: 무량수전 설경 (보도)

## 가는 법
- 과거 기사(2013)에 27번 버스가 부석사·소수서원·풍기역 등을 연결한다고 나오나 현행 노선은 미확인.

## 주변 연계 코스
- 소수서원 (여행 매체 연계 코스 소개)

## 팁
- 석양 무렵 조망이 특히 좋음. 일몰 시각은 날짜별로 확인.
