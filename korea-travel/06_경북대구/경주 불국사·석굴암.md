# 경주 불국사·석굴암

| 항목 | 내용 |
|---|---|
| 소재지 | 불국사 경북 경주시 불국로 385(진현동) / 석굴암 경주시 석굴로 238(진현동) |
| 분류 | 유네스코 세계유산(1995) |
| 추천 시기 | 봄·가을 (겹벚꽃 시즌은 4월 중순경, 해마다 상이) |
| 운영·요금 | 불국사 09:00~18:00(입장 17:00 마감)로 안내되나 09:00~17:00로 적은 자료도 있어 자료별로 상이, 공식 확인 필요. 석굴암은 계절별(3~9월 18:00, 2·10월 17:30, 11~1월 17:00까지)로 안내되나 공식 확인 필요. 관람료 무료(2023-05부터 국가 지원), 연중무휴(2026-10 기준, 공식 확인 필요) |
| 주차 | 불국사 주차 1,000원 안내(2026-10 기준, 공식 확인 필요). 석굴암 주차는 1,000원/2,000원으로 자료별 상이 |
| 예약 | 미확인(공식 확인 필요) |

## 볼거리
- 불국사: 다보탑·석가탑, 대웅전 일원
- 석굴암 본존불
- 불국사 공원 겹벚꽃(봄)

## 계절별 포인트
- 봄: 불국사 공원 겹벚꽃 (여러 보도)
- 겨울: 다보탑·석가탑 설경 (보도)

## 가는 법
- 불국사와 석굴암은 별도 이동 필요(토함산 도로). 불국사~석굴암 셔틀버스 여부는 미확인.

## 주변 연계 코스
- 대릉원·첨성대·동궁과 월지 (경주 시내 코스)

## 팁
- 문의: 불국사 054-746-9913, 석굴암 054-746-9933 (제3자 자료 기준, 공식 확인 필요)
