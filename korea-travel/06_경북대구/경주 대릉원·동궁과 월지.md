# 경주 대릉원·동궁과 월지

| 항목 | 내용 |
|---|---|
| 소재지 | 대릉원 경북 경주시 황남동 일원(도로명 주소 미확인) / 동궁과 월지 경주시 원화로 102 |
| 분류 | 고분·야경 |
| 추천 시기 | 해질녘~야간 |
| 운영·요금 | 대릉원 본체는 2023-05-04부터 무료, 09:00~22:00 보도(2023 기준). 천마총 별도 유료: 2,000원(2023 기사) vs 3,000원(시점 불명 자료)으로 상이. 동궁과 월지 성인 3,000원, 09:00~22:00(입장 21:30 마감)은 블로그 기준(2026-10 기준, 공식 확인 필요) |
| 예약 | 미확인(공식 확인 필요) |

## 볼거리
- 천마총(내부 관람 가능)
- 대릉원 고분군(23기 안팎 보도)
- 첨성대
- 동궁과 월지 야경(수면 반영)

## 계절별 포인트
- 겨울: 고분군·월지 설경 (보도)
- 사계절 해질녘~야경 추천

## 가는 법
- 미확인(대중교통·주차 요점은 경주시 공식 안내 확인 필요)

## 주변 연계 코스
- 황리단길, 첨성대, 불국사·석굴암(별도 이동)

## 팁
- 황리단길과 가까워 저녁 코스로 적합. 대릉원은 야간 출입이 엄격히 통제된다는 보도(2023)가 있어 운영시간 확인.
