# 한국 여행지 정리

권역별 폴더로 나눈 한국의 대표 여행지 모음. 각 폴더의 `README.md` 에 권역 개요와 여행지 표가, 여행지별 문서에 볼거리·추천 시기·팁이 있다.

> **자료 기준 (2026-10-09)**: 한국어 웹검색 결과(언론·관광정보 사이트·블로그)로 보강했다. 이 작업 환경에서는 공식 사이트(국가유산청·한국관광공사·지자체·시설 홈페이지) 본문을 열 수 없어 **공식 원문으로 직접 확인한 항목은 없다**. 요금·운영시간·휴무일·예약 규정은 모두 "(기준일, 공식 확인 필요)"로 병기했고, 자료끼리 다른 항목은 "자료별 상이"로 남겼으며, 확인 못 한 것은 "미확인"으로 표기했다. 방문 전 반드시 공식 안내를 확인할 것.
