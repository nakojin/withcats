# 한국 여행 자료 모음 · 기존 자료 후속 재검증

조사 기준일: 2026-10-10. 1·2차의 연구자료와 원문 기록을 보존하고, 남아 있던 기존35문서를 공식 출처로 재검토했다.

## 실제 규모와 상태

- 전체 연구레코드 321개. 도시·복합·상위 참고와 BOK 상세근거보류를 제외한 연구용 편집 집계는 292개다.
- 기존 장소 문서56개 중 공식 핵심정보 확인 56개, 재검증 대기 0개다.
- 기존35문서의 핵심정보 보강: 35개 완료, 0개 보류. 상태를 갱신한 작업으로 변동 운영정보는 일부 미확인이다. 신규 장소 문서를 추가한 작업이 아니다.
- 연구용 집계282→292의 증가는 기존10개 문서의 검증 전환에 따른 것이다. 새 독립 목적지 문서를10개 추가한 것이 아니다.
- 이전 신규 상세 연구레코드265개는 그대로이며 BOK1개는 계속 보류·집계 제외다.
- 전체 장소 문서는321개다. 문서 수와 검증된 독립 물리적 명소 수는 같지 않다.

이 집계는 명명된 목적지와 복합 방문권이 섞인 편집레코드 수다. 도시·광역 부모와 하위 장소를 동시에 독립 명소로 가산하지 않는다. 한 문서에 나오는 구성요소를 각각 신규 명소로 늘리지 않았다. 지역 폴더는 여행 편집권역이며 행정구역 개편이나 법적 경계 변경을 뜻하지 않는다.

## 이용할 때 확인할 점

볼거리·위치의 공식 핵심정보 확인과 방문일 요금·시간·예약 확인은 다르다. 추천 계절·동선은 편집 판단 표시를 유지한다. 운영값의 null은 무료나 예약 불필요라는 뜻이 아니다. 전체 자료를 현행 운영조건까지 전수 인증한 완성 여행 원고로 표현하지 않는다. 총괄 원문 재대조는 하회마을·설악케이블카·해운대 해변열차·에버랜드·한국민속촌 5곳 표본에 한정되며 전체35문서의 전수 이중검증을 뜻하지 않는다.

BOK는 공식 본문 재확보에 실패해 상세 여행 활용의 보류 상태를 유지했다. 검색 요약의 주소·주차·좌석값을 확정값으로 옮기지 않았다.
