# N서울타워(남산)

| 항목 | 내용 |
|---|---|
| 소재지 | 서울 용산구 남산공원길 105 |
| 분류 | 전망·야경 |
| 추천 시기 | 해질녘 |
| 운영·요금 | 전망대 평일 10:30~22:30, 주말·공휴일 10:00~23:00, 매표 마감 30분 전(예약 사이트 기준, 2026-10 기준, 공식 확인 필요). 전망대 요금 미확인 |
| 예약 | 케이블카는 현장 매표가 기본(자료 기준). 전망대는 온라인 예매 가능한 판매처 있음 |

## 볼거리
- 전망대, 남산 둘레길(북측순환로는 차량·자전거 통행 금지, 도보 전용)
- 야경

## 가는 법
- 남산은 승용차·택시 진입 불가(서울시 기사 기준). 순환버스 01번 이용, 단방향 운행이라 종점에서 재탑승 시 환승 불가(자료 기준, 노선 변경 가능성 있어 확인 필요)
- 남산케이블카: 하부 승강장 서울 중구 소파로 83, 명동역에서 도보. 왕복 15,000원·편도 12,000원(블로그·기사 일치, 2026-10 기준, 공식 확인 필요). 하행 막차 22:00
- 주차 요금·할인은 미확인

## 주변 연계 코스
- 명동, 남산골한옥마을은 이번 검색에서 미확인

## 팁
- 주말 저녁 케이블카 대기가 1시간 이상일 수 있음(기사 기준), 불법주차 단속 주의.
