# 경복궁

| 항목 | 내용 |
|---|---|
| 소재지 | 서울 종로구 사직로 161 (기존 지식, 이번 검색에서 번호 미확인) |
| 분류 | 고궁·역사 (조선 법궁) |
| 추천 시기 | 봄·가을 |
| 운영·요금 | 휴궁 화요일(자료상, 2026-10 기준, 공식 확인 필요). 성인 3,000원(2018·2023 기사, 공식 확인 필요). 관람시간 미확인 |
| 예약 | 낮 관람은 현장 입장. 야간관람은 별도 예매제 |

## 볼거리
- 근정전, 경회루, 향원정
- 수문장 교대의식: 10:00·14:00, 약 20분(2026-10 기준 자료, 공식 확인 필요). 2026-08 폭염으로 전 일정 중단된 적 있어 운영 여부 확인
- 광화문 파수의식: 11:00·13:00, 약 10분(서울시 자료 기준)

## 계절별 포인트
- 야간관람: 2026 하반기는 9/2~10/2로 종료(예매 사이트 기준). 일정은 매년 달라 공식 공지 확인

## 가는 법
- 지하철 3호선 경복궁역, 5호선 광화문역 이용이 일반적(이번 검색에서 출구 미확인). 주차는 미확인

## 주변 연계 코스
- 북촌한옥마을·광화문과 묶어 반나절 코스

## 팁
- 한복 착용 무료입장: 자료마다 예매 필요 여부가 상이, 공식 확인 필요. 규정에 맞지 않는 한복은 불가 조건이 있음.
