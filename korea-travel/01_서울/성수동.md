# 성수동

| 항목 | 내용 |
|---|---|
| 소재지 | 서울 성동구 성수동 일대 |
| 분류 | 트렌드·카페 |
| 추천 시기 | 주말 오후(붐빔), 한가한 시간은 평일 오전·이른 오후 |
| 운영·요금 | 상점별 상이, 팝업·카페 영업시간은 개별 확인 |
| 예약 | 인기 팝업·카페는 사전 예약·웨이팅 많음(후기 기준, 개별 확인) |

## 볼거리
- 공장·창고를 개조한 카페(대림창고, 카페 어니언 등)와 붉은 벽돌 거리
- 팝업스토어, 서울숲 카페거리(서울숲2길·4길)
- 서울숲: 은행나무숲길은 11월 말 낙엽이 장관(블로그 기준)

## 계절별 포인트
- 가을: 서울숲 은행나무숲길. 서울숲-성수 커넥트 해설투어 2026년 5~10월 운영, 사전 접수(서울시 자료)

## 가는 법
- 서울숲역(수인분당선) 도보 약 5분 안내 있음. 성수역(2호선)은 일반 지식으로 이번 검색에서 미확인

## 주변 연계 코스
- 서울숲, 성수-서울숲 카페거리

## 팁
- 상권이 빠르게 바뀌므로 방문 전 최신 영업 정보 확인. 주말 인기 카페는 대기가 있음.
