# 창덕궁

| 항목 | 내용 |
|---|---|
| 소재지 | 서울 종로구 율곡로 99 |
| 분류 | 유네스코 세계유산(1997) |
| 추천 시기 | 가을(단풍) |
| 운영·요금 | 휴궁 월요일(공휴일이면 다음 평일). 전각 성인 3,000원, 후원 별도 약 5,000원(블로그·기사 기준, 2026-10 기준, 공식 확인 필요). 관람시간 미확인 |
| 예약 | 후원은 예약제(언어별 시간·회차 정원 100명, 온라인 50·현장 50 / 자료 기준). 전각 표와 별도 구매 |

## 볼거리
- 인정전, 낙선재
- 후원(비원): 해설 동반 관람 위주. 일반 약 60분, 심화 약 90분(블로그 기준)

## 계절별 포인트
- 가을 단풍 시기 후원은 인기가 높아 예약 경쟁이 있음. 2023년에는 10~11월 정원 확대·자유관람 시범이 있었으나 올해 적용은 미확인
- 겨울 설경 산책 소개 있음(서울시 미디어허브)

## 가는 법
- 지하철 3호선 안국역 이용이 일반적(이번 검색에서 미확인). 주차는 미확인

## 주변 연계 코스
- 북촌한옥마을, 창경궁(월요일 휴관 자료 있음), 경복궁

## 팁
- 2027-01-01부터 궁·능 관람료 새 기준 적용 예정(국가유산청 발표 11월 예정, 기사 기준).
- 수요일 무료 개방(2026-10-07 시작, 후원 제외)은 블로그 1건뿐이라 미확인.
- 예매는 궁능유적본부 통합예약, 카드 결제만 가능(블로그 기준).
