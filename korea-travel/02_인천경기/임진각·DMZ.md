# 임진각·DMZ

| 항목 | 내용 |
|---|---|
| 소재지 | 경기 파주시 (임진각 관광지, 정확한 도로명 주소 미확인) |
| 분류 | 분단 역사·안보 |
| 추천 시기 | 봄·가을 |
| 가는 법 | 미확인(길찾기 앱 확인) |
| 운영·요금 | 임진각 관광지 24시간·연중무휴 소개 자료 있음(오래된 기사). 평화곤돌라 09:00~18:00(입장마감 17:30), 대인 입장료 9,000원+일반캐빈 왕복 12,000원 등(제3자, 연도 미상) (2026-10 기준, 공식 확인 필요) |
| 예약 | 곤돌라는 온라인 예매 후 현장 발권 안내. 민통선 진입 시 보안서약서·대표자 실물 신분증 필요 |

## 볼거리
- 자유의 다리(1953년 포로 교환 장소로 알려짐), 평화누리공원(2005년 조성)
- 임진각 평화곤돌라(임진각~캠프그리브스, 크리스탈 캐빈), 전망대
- DMZ 안보관광: 임진각 매표소 신청, 신분증 필수(2016년 기사). 파주 DMZ 평화관광(문산자유시장·캠프그리브스 연계) 운영 사례

## 계절별 포인트
- 확인된 자료 없음(봄·가을 추천은 기존 내용 유지, 근거 미확인)

## 주변 연계 코스
- 캠프그리브스(곤돌라 연계), 도라산역 연계 DMZ 관광(2026-02 파주시 자료에 언급, 현행 운영 미확인)

## 팁
- 안보관광 일부 코스는 사전 신청·신분증 필요, 운영은 수시 변동. 문의: 곤돌라 031-952-6388, 임진각 031-953-4744(제3자 자료)
