# 한국민속촌

| 항목 | 내용 |
|---|---|
| 소재지 | 경기 용인시 기흥구 민속촌로 90 |
| 분류 | 전통 체험 |
| 추천 시기 | 봄·가을 |
| 가는 법 | 기흥역·상갈역 인근 버스(10-5·88·88-1), 강남발 5001-1 / 에버라인 전대·에버랜드역에서 37번 환승(제3자 자료) |
| 운영·요금 | 평일 10:00~19:00, 금·토·일/공휴일 10:00~22:00(월별 변동), 연중무휴. 성인·청소년 37,000원·아동 30,000원·경로 25,000원 (2026-10 기준, 자료별 상이: 35,000원 안내도 있음, 공식 확인 필요) |
| 예약 | 온라인 예매 가능(할인 있음), 필수 여부 미확인 |

## 볼거리
- 전통 가옥(민속마을)·세계민속관, 정기 공연, 전통 먹거리, 놀이마을 어트랙션

## 계절별 포인트
- 가을: 단풍 소개 기사 다수(개화·단풍 시기는 미확인)
- 야간·여름: 2025년엔 금·토·일/공휴일 야간개장, 7/25~8/24 심야 운영 사례. 2026년 일정 미확인

## 주변 연계 코스
- 에버랜드(같은 용인, 이동 시간 미확인)

## 팁
- 주차 소형 2,000원·대형 3,000원(2025 이후 가이드, 공식 확인 필요). 야간 행사 운영 여부는 시즌별로 확인. 문의 031-288-0000(오래된 기사)
