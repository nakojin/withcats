# 강화도

| 항목 | 내용 |
|---|---|
| 소재지 | 인천 강화군 (부근리 지석묘: 강화군 하점면 부근리) |
| 분류 | 역사·자연 |
| 추천 시기 | 봄·가을 |
| 가는 법 | 대중교통은 배차가 길어 차량·자전거 이동이 수월. 석모도는 2017년 석모대교 개통으로 차량 진입 가능(개통일은 6/28 vs 7월로 자료별 상이) |
| 운영·요금 | 석모도 미네랄온천 07:00~21:00 화요일 휴관, 성인 9,000원 안내(제3자, 2026-10 기준, 공식 확인 필요) |
| 예약 | 미확인 |

## 볼거리
- 강화 부근리 지석묘(사적 137호, 탁자식): 고창·화순과 함께 2000년 유네스코 세계유산 등재(11/29 vs 12/2로 자료별 상이)
- 마니산 참성단(사적 136호): 2019년 통행 금지, 2023년 재개방 보도. 현재 출입 방식·개천절 행사 때 통제는 공식 확인 필요
- 석모도 보문사 눈썹바위 낙조, 강화나들길(석모도 11코스 바람길 등)

## 계절별 포인트
- 가을: 강화를 걷는 나들길 기사 있음(구체 시기 미확인)
- 일몰: 석모도 보문사 서해 낙조 유명

## 주변 연계 코스
- 석모도 보문사+미네랄온천(오후 입도 후 일몰, 온천 마감 확인). 외포리~석포리 페리 현행 시간은 미확인

## 팁
- 대중교통은 배차가 길어 차량 이동이 수월. 주말 석모대교 정체 후기 있음
