# 두물머리

| 항목 | 내용 |
|---|---|
| 소재지 | 경기 양평군 양서면 두물머리길 145 |
| 분류 | 자연·사진 (한국관광 100선 다수 선정) |
| 추천 시기 | 새벽·가을 |
| 가는 법 | 경의중앙선 양수역에서 도보(자료별 12~20분). 자차는 두물머리 공영주차장, 주말 일찍 도착 권장 |
| 운영·요금 | 상시 개방·입장료·주차비 무료 안내(2026-10 기준, 공식 확인 필요). 문의 양평군 관광과 031-770-1067 |
| 예약 | 불필요 |

## 볼거리
- 남한강·북한강 합류 지점, 400년 넘은 느티나무
- 황포돛배, 물안개(이른 아침)

## 계절별 포인트
- 새벽~일출: 물안개·일출 사진
- 여름: 인접 세미원 연꽃(2026 연꽃문화제 6/26~8/17 종료)
- 가을·겨울: 느티나무·일출 풍경 기사 있음

## 주변 연계 코스
- 세미원(출구가 두물머리 산책로와 연결, 성인 5,000원 — 2026-10 기준, 공식 확인 필요)

## 팁
- 일출 직후가 사진 촬영 적기. 주차 규모는 미확인
