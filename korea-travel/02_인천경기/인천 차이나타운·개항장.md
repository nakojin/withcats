# 인천 차이나타운·개항장

| 항목 | 내용 |
|---|---|
| 소재지 | 인천 중구 (인천역 맞은편 패루 일대, 상세 주소 미확인) |
| 분류 | 근대 역사·먹거리 |
| 추천 시기 | 사계절 |
| 가는 법 | 1호선 인천역 하차, 광장 건너 패루(中華街). 짜장면박물관은 1번 출구 도보 약 5분, 전용 주차장 없음 |
| 운영·요금 | 짜장면박물관 09:00~18:00(입장마감 17:30), 월요일·1/1·설추석 당일 휴관, 성인 1,000원·청소년 700원·65세 이상/어린이 무료 (2026-10 기준, 공식 확인 필요) |
| 예약 | 개인은 불필요, 단체는 사전 예약 안내 |

## 볼거리
- 개항장 근대 건축: 근대건축전시관(옛 일본 제18은행 인천지점, 시 유형문화재 50호), 인천아트플랫폼, 개항박물관
- 짜장면박물관, 차이나타운 패루

## 계절별 포인트
- 확인된 계절별 자료 없음(사계절 추천은 기존 내용 유지)

## 주변 연계 코스
- 송월동 동화마을(24시간 무료 개방 안내), 자유공원, 월미도(인천역에서 거리가 있어 버스·택시 권장), 신포국제시장·답동성당

## 팁
- 월미도·송월동 동화마을과 연계하면 하루 코스. 박물관 문의 032-773-9812(제3자 자료)
