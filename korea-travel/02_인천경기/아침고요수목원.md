# 아침고요수목원

| 항목 | 내용 |
|---|---|
| 소재지 | 경기 가평군 상면 수목원로 432 (축령산 자락) |
| 분류 | 정원(약 33만㎡, 20여 개 테마정원, 5,000여 종 식물) |
| 추천 시기 | 봄 꽃·겨울 점등 |
| 가는 법 | 대중교통 경로 미확인(길찾기 앱 확인). 서울발 수목원+남이섬 유료 버스투어 사례 있음(2026-03-16~12-04 운영 안내) |
| 운영·요금 | 평소 08:30~19:00, 연중무휴 안내. 성인 11,000원·청소년 8,500원·어린이 7,500원이 다수이나 9,000원 안내도 있어 자료별 상이 (2026-10 기준, 공식 확인 필요) |
| 예약 | 미확인(오색별빛정원전 기간 예매 여부 공식 확인 필요) |

## 볼거리
- 한국정원 등 테마정원, 계절 꽃
- 오색별빛정원전: 겨울 LED 점등 축제(통상 12월~3월)

## 계절별 포인트
- 봄: 봄꽃·정원 산책
- 가을: 단풍 소개 기사 있음
- 겨울: 최근 확인된 회차는 2024-12-06~2025-03-16. 2026-27 겨울 일정 미확인, 점등 기간 운영시간은 자료별 상이(11:00~21:00 vs 17:00~21:00)

## 주변 연계 코스
- 남이섬(강원 춘천)·자라섬(가평)과 묶어 가평·춘천 코스 가능

## 팁
- 주말은 주차 혼잡(주차 요금 미확인). 공식 사이트 morningcalm.co.kr에서 최신 확인
