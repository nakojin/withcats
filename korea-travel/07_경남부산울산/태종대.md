# 태종대

| 항목 | 내용 |
|---|---|
| 소재지 | 부산광역시 영도구 전망로 24 (동삼동) |
| 분류 | 해안 절벽 |
| 추천 시기 | 사계절 |
| 운영·요금 | 유원지 하절기(3~10월) 04~24시 / 동절기(11~2월) 05~24시, 연중무휴 (자료 기준, 공식 확인 필요) |
| 예약 | 불필요 |

## 볼거리
- 영도등대, 절벽 산책로(국가지질공원)
- 다누비 순환열차: 전면 운행 중단 보도 있음 (중단 시점·재개 여부 미확인). 과거 요금 성인 4,000원 / 청소년 2,000원 / 소인 1,500원

## 계절별 포인트
- 계절별 추천 미확인.

## 가는 법
- 중단 기간 대체로 무료 순환버스(수~일 운행, 월·화 휴무)를 안내하는 블로그가 있으나 공식 공지 미확인.

## 주변 연계 코스
- 미확인

## 팁
- 정정: 기존 문서의 '순환열차 이용' 팁은 현재 운행 여부 불확실. 방문 전 부산관광공사 051-405-8745 / 태종대 공식 페이지(bisco.or.kr/taejongdae)로 확인.
