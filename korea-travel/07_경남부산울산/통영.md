# 통영

| 항목 | 내용 |
|---|---|
| 소재지 | 경상남도 통영시 |
| 분류 | 항구·예술 |
| 추천 시기 | 봄 (케이블카 후기에 진달래 언급, 공식 미확인) |
| 운영·요금 | 케이블카 아래 참조 (2026-10 기준, 공식 확인 필요) |
| 예약 | 불필요 (케이블카 현장 대기 가능성, 미확인) |

## 볼거리
- 동피랑 벽화마을: 통영시 동피랑1길 6-18, 상시 개방·무료
- 통영 케이블카(한려수도 조망): 통영시 발개로 205, 미륵산 상부역, 약 10분. 운영 동절기(10~3월) 09:30~16:00 / 4·9월 ~17:00 / 5~8월 ~18:00, 왕복 성인 15,000원 / 청소년 12,000원 / 어린이 10,000원 (블로그 기준)
- 충무김밥

## 계절별 포인트
- 봄: 케이블카 후기에 진달래 언급 (계절별 공식 정보는 미확인).

## 가는 법
- 동피랑 주차: 통제영주차장·태평공영주차장(유료). 대중교통 미확인.

## 주변 연계 코스
- 통영 중앙시장 해산물과 꿀빵 (기존 내용, 별도 확인 못함). 케이블카와 한려수도 유람선 연계 소개 기사 있음.

## 팁
- 케이블카 요금·시간은 통영관광개발공사 확인.
