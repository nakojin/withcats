# 광안리·광안대교

| 항목 | 내용 |
|---|---|
| 소재지 | 부산광역시 수영구 (광안해변로 일대) |
| 분류 | 해변·야경 |
| 추천 시기 | 야간 |
| 운영·요금 | 해변 상시 개방. 드론라이트쇼 무료 (2026-10 기준, 공식 확인 필요) |
| 예약 | 불필요 |

## 볼거리
- 광안대교 야경: 2024-01 LED 경관조명 개선 점등. 점등·소등 시간표는 미확인
- 광안리 M드론라이트쇼: 10~2월 매주 토 19시·21시, 3~9월 20시·22시 (약 12분, 무료). 2026-10 기준 부산시 공지, 날씨에 따라 하루 전 또는 당일 취소·지연 가능
- 해변 카페거리

## 계절별 포인트
- 광안리 해수욕장 2026 개장: 7/1~8/31 (보도 기준, 공식 확인 필요)
