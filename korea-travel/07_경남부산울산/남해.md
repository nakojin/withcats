# 남해

| 항목 | 내용 |
|---|---|
| 소재지 | 경상남도 남해군 |
| 분류 | 섬·마을 |
| 추천 시기 | 봄·가을 (독일마을은 봄 풍경 소개 기사 있음) |
| 운영·요금 | 보리암 입장료 자료별로 상이(성인 1,000원 vs 2명 2,000원 취지), 공식 확인 필요. 다랭이마을 입장 무료 (2026-10 기준) |
| 예약 | 불필요 (다랭이마을 체험은 별도) |

## 볼거리
- 독일마을: 경남 남해군 삼동면 물건리 1074-2, 파독전시관(2014-06 개관)·독일식 식당가
- 다랭이마을(가천): 남해군 남면 남면로 702, 계단식 논, 남파랑길 42코스 경유, 체험은 유료
- 보리암: 남해군 상주면 보리암로 665, 금산 사찰, 일출 명소

## 계절별 포인트
- 그 외 계절별 정보 미확인.

## 가는 법
- 대중교통이 불편해 자가용·렌터카 사실상 필수라는 안내가 다수. 노선 상세는 미확인.

## 주변 연계 코스
- 다랭이마을, 보리암, 물미해안도로를 묶는 일정이 일반적 (여행 블로그 기준).

## 팁
- 대중교통이 불편해 차량 이동 권장.
- 요금·운영시간은 남해군청 또는 한국관광공사에서 확인 필요.
