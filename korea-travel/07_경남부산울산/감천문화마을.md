# 감천문화마을

| 항목 | 내용 |
|---|---|
| 소재지 | 부산광역시 사하구 감내2로 203 (감천동) |
| 분류 | 마을·사진 |
| 추천 시기 | 사계절 (한낮 혼잡 회피: 오전 이른 시간) |
| 운영·요금 | 상시 개방, 입장 무료. 안내센터 스탬프투어 지도 2,000원 (2026-05 보도 기준, 공식 확인 필요) |
| 예약 | 불필요 |

## 볼거리
- 산비탈에 파스텔 톤 집이 계단식으로 이어진 컬러풀 골목, 벽화
- 어린왕자와 사막여우 포토존
- 스탬프 투어(안내센터 지도 구입)

## 계절별 포인트
- 계절별 추천은 공식 자료로 미확인. 사계절 방문 가능하다는 정도만 확인.

## 가는 법
- 대중교통·주차 상세는 미확인. 안내센터 문의 051-204-1444 (2026-05 기준, 공식 확인 필요).

## 주변 연계 코스
- 미확인 (자료 부족)

## 팁
- 언덕 골목이 많아 운동화 필수.
- 2025-02 보도: 사하구가 방문 시간 제한·입장료 부과 여부 용역 진행. 이후 정책은 사하구청에 확인.
- 운영시간 표기가 자료별로 상이(상시 개방 vs 3~10월 9~18시/11~2월 9~17시). 공식 확인 필요.
