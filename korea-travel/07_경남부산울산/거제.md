# 거제

| 항목 | 내용 |
|---|---|
| 소재지 | 경상남도 거제시 |
| 분류 | 섬 |
| 추천 시기 | 봄·가을 (바람의 언덕은 동백 시기 후기 있음, 공식 미확인) |
| 운영·요금 | 아래 볼거리 참조 (모두 2026-10 확인 기준, 공식 확인 필요) |
| 예약 | 외도 유람선은 사전 예약·출항 전 도착 권장 |

## 볼거리
- 외도 보타니아: 입장료 성인 11,000원 / 중고생 8,000원 / 어린이 5,000원 (유람선 별도). 운영시간 자료별로 상이(08:00~19:00 vs 08:00~17:00), 공식 확인 필요
- 외도 유람선(와현 출발): 왕복 대인 23,000원 안팎, 소인 14,000~15,000원 (블로그 기준, 공식 확인 필요)
- 바람의 언덕: 무료, 유료 주차장 약 3,000원 (후기 기준), 운영시간 미확인
- 거제 포로수용소 유적공원: 09:00~18:00(매표 17:00까지), 매주 화요일 휴관, 성인 7,000원 / 청소년·군인 5,000원 / 어린이 3,000원, 문의 055-639-0625

## 계절별 포인트
- 계절별 공식 자료 미확인. 외도는 기상에 따라 결항 가능.

## 가는 법
- 미확인 (선착장별 시간표는 외도랑 oedorang.com / 0507-1409-2172 확인)

## 주변 연계 코스
- 미확인. 외도 유람선은 장승포·와현 등 선착장별로 출발지가 다름.

## 팁
- 외도는 유람선 예약·기상 확인 필요. 주말엔 출항 30분 전 도착 권장.
- 포로수용소는 화요일 휴관 주의.
