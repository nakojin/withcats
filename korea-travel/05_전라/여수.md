# 여수

| 항목 | 내용 |
|---|---|
| 소재지 | 전남 여수시 |
| 분류 | 해양·야경 |
| 추천 시기 | 사계절 |
| 케이블카 | 09:30~21:30(매표 21:00) 안내 다수, 주말 시간·요금은 자료별로 상이(일반캐빈 왕복 대인 15,000~17,000원), 기상 시 중단 (2026-10 기준, 공식 확인 필요) |
| 오동도 | 입장 무료, 동백열차 편도 1,000원(할인 500원), 주차 30분 무료 후 30분당 500원·일 최대 5,000원 (여수시 안내, 2026-10 기준, 공식 확인 필요) |
| 향일암 | 입장료 자료별로 상이(관광공사 기사 성인 2,500원 vs 여수시 사이트 무료 표기), 공식 확인 필요 |

## 볼거리
- 여수 밤바다, 오동도(섬 연중 개방), 해상케이블카, 향일암(돌산도)

## 계절별 포인트
- 겨울~봄: 오동도 동백 (일반 지식, 개화 시기 미확인)

## 가는 법
- KTX 여수엑스포역: 서울 기준 약 2시간 40분(여수시 보도자료). 오동도까지 도보 약 10분 또는 시내버스 2번.
- 향일암: 엑스포역에서 시내버스 111번 (116번도 운행). 향일암 주차장은 소규모라는 블로그 정보.

## 주변 연계 코스
- 엑스포역 - 오동도 - 진남관 - 해양수산과학관 - 향일암 - 수산시장 (여수시 코스 안내)

## 팁
케이블카 온라인 할인은 전날까지 구매 권장, 강풍 시 운행 중단 가능.
