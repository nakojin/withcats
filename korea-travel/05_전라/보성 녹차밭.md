# 보성 녹차밭

| 항목 | 내용 |
|---|---|
| 소재지 | 전남 보성군 보성읍 녹차로 763-43 (대한다원, 여행 안내 글 기준) |
| 분류 | 차밭 |
| 추천 시기 | 봄~여름 (어린 찻잎 4~5월 소개) |
| 운영·요금 | 09:00~18:00, 성인 4,000원·청소년/경로/군인 3,000원·지역주민/장애인 2,000원 (여행 안내 글, 2026-10 기준, 공식 확인 필요) |
| 휴무·예약 | 미확인 / 예약 불필요로 보이나 미확인 |

## 볼거리
- 계단식 녹차밭(대한다원, 해발 약 350m 언덕), 중앙전망대
- 녹차 체험

## 계절별 포인트
- 봄: 새순 돋는 4~5월 / 겨울: 녹차밭 위 설경 소개 글 있음

## 가는 법
대중교통·주차 미확인.

## 주변 연계 코스
- 순천만(에코투어 가이드 글에서 연계 소개), 그 외 미확인

## 팁
새벽 안개 낀 아침이 풍경 좋음. 차밭에 그늘이 적어 모자·양산 권장. 대한다원 외 보성 차밭도 있으므로 방문지 확인.
