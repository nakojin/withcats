# 담양

| 항목 | 내용 |
|---|---|
| 소재지 | 전남 담양군 (죽녹원: 담양읍 죽녹원로 119 또는 객사7길 37, 자료별 상이 / 소쇄원: 가사문학면 소쇄원길 17) |
| 분류 | 숲·정원 |
| 추천 시기 | 여름 초록·가을 |
| 죽녹원 | 3~10월 09:00~19:00, 11~2월 09:00~18:00, 연중무휴, 성인 3,000원·청소년/군인 1,500원·초등 1,000원 (2026-10 기준, 공식 확인 필요) |
| 소쇄원 | 성인 2,000원, 65세 이상·만 6세 이하 등 무료. 마감 계절별(여름 19시/동절기 17시 안내), 자료별 상이 |
| 메타세쿼이아길 | 성인 2,000원 안내 글 있으나 최신 징수·시간 자료별로 상이, 군청 확인 필요 |

## 볼거리
- 죽녹원(대나무숲), 메타세쿼이아 가로수길, 소쇄원(국가명승 제40호, 2008 지정)
- 관방제림: 입장료 없음, 약 2km 천연기념물 숲길(블로그 기준)

## 계절별 포인트
- 여름: 대나무·가로수 초록 / 겨울: 눈 쌓인 메타세쿼이아길 소개 글 있음

## 가는 법
- 대중교통 미확인. 메타세쿼이아길 인근 주차장은 자료상 '메타프로방스 무료/매표소 주차장'.

## 주변 연계 코스
- 죽녹원 - 관방제림 - 메타세쿼이아길(당일 코스로 소개), 소쇄원은 별도 이동

## 팁
대나무 숲은 비 온 뒤 미끄러움에 유의. 대나무축제 기간 입장료 환급 행사가 있었음(2026 기사).
