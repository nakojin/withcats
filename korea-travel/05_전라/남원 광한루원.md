# 남원 광한루원

| 항목 | 내용 |
|---|---|
| 소재지 | 전북특별자치도 남원시 요천로 1447 (천거동) |
| 분류 | 전통 정원 (국가 명승 제33호, 광한루 건물은 보물 제281호) |
| 추천 시기 | 봄 |
| 운영시간 | 하절기(4~10월) 08:00~20:00 또는 21:00, 동절기 08:00~20:00 (자료별로 상이), 연중무휴 안내 (2026-10 기준, 공식 확인 필요) |
| 요금 | 2020년 기사: 성인 3,000원·청소년/군인 2,000원·어린이 1,500원, 야간(18시 이후) 무료개장. 현재 요금 미확인, 공식 확인 필요 |
| 예약 | 불필요로 보임(미확인). 문의 063-620-8905 |

## 볼거리
- 광한루, 오작교, 춘향 사당, 월매집, 춘향 설화
- 호수와 정원, 저녁 야경(무료 개장 시간대 이용 가능)

## 계절별 포인트
- 봄: 기존 추천 유지. 춘향제(2020년 기사에 제90회 언급, 올해 일정 미확인)

## 가는 법
- 주차 승용차 2,000원, 18시 이후 무료 (블로그 1곳, 공식 확인 필요). 대중교통 미확인.

## 주변 연계 코스
- 지리산 방면 연계(기존 내용), 춘향테마파크(설 명절 광한루원과 함께 무료 개관한 사례 기사)

## 팁
설 명절 등 무료 개관 사례가 있음. 저녁 식사 후 야경 방문 추천.
