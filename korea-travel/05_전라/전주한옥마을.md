# 전주한옥마을

| 항목 | 내용 |
|---|---|
| 소재지 | 전북특별자치도 전주시 완산구 (경기전 주소: 태조로 44) |
| 분류 | 한옥·먹거리 |
| 추천 시기 | 사계절 |
| 경기전 요금 | 1,000~3,000원 범위로 안내, 만 65세 이상·만 6세 이하 무료, 문화가 있는 날(매월 마지막 수) 무료 (2026-10 기준, 공식 확인 필요) |
| 경기전 시간 | 시즌별 상이: 전주시 페이지는 하계(6~8월) 09:00~20:00, 타 자료는 3~10월 09:00~19:00·11~2월 09:00~18:00 (자료별로 상이, 공식 확인 필요) |
| 예약 | 입장 예약 불필요(미확인 시 현장 입장), 한옥 숙박은 사전 예약 |

## 볼거리
- 경기전: 어진(왕 초상) 봉안 건물군, 경내 어진박물관은 경기전 입장 시 무료
- 전동성당: 호남 최대·최고(最古) 서양식 근대건축으로 소개됨
- 오목대, 전통시장(주말 야시장), 한복체험, 비빔밥
- 경기전 수문장 교대의식(2025년 기사 기준 6·9·11월 토 14:00 개최, 올해 일정 미확인)

## 계절별 포인트
- 봄·가을: 경기전 숲길 산책 (경기전 5월 푸른 풍경 소개 글 있음)

## 가는 법
- 한옥마을 주소는 단일 확인 못 함. 내비에는 목적지 주차장/건물 주소 입력 권장.
- 주차(2026-09 기준, 블로그 1곳): 제1·2공영 기본 30분 1,200원·일 최대 14,400원, 제4공영 무료+주말·공휴일 셔틀(10:00~18:30 탄력). 공식 확인 필요.
- 버스 노선: 최신 정보 미확인.

## 주변 연계 코스
- 경기전 - 전동성당 - 오목대 도보 이동 가능

## 팁
주말·연휴엔 혼잡. 한옥 숙박은 사전 예약. 경기전 일부 전시공간 휴실 공지 있었음.
