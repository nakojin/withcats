# 목포

| 항목 | 내용 |
|---|---|
| 소재지 | 전남 목포시 (원도심 근대역사문화공간, 유달산) |
| 분류 | 항구·근대 역사 |
| 추천 시기 | 가을 |
| 해상케이블카 | 하절 월~목 09:00~20:00·금~일 09:00~21:00 안내, 일요일 시간 자료별로 상이, 매표 종료 1시간 전, 연중무휴(기상 시 중단) (2026-10 기준, 공식 확인 필요) |
| 케이블카 요금 | 일반캐빈 왕복 성인 24,000원·소인 18,000원 (예약 사이트, 미검증, 공식 확인 필요) |
| 근대역사문화공간 | 전체 휴무·개방시간 미확인, 건물별 상이 |

## 볼거리
- 유달산, 해상케이블카
- 근대역사문화공간: 1897 개항기 이후 원도심. 구 일본영사관 등 국가등록문화유산 다수(보도 기준 15건)

## 계절별 포인트
- 확인된 것 없음(가을 추천은 기존 내용 유지)

## 가는 법
대중교통·주차 미확인. 시티투어 버스가 있다는 안내 글 있음(노선·요금 미확인).

## 주변 연계 코스
- 원도심 근대건축 도보 탐방 - 유달산 - 케이블카

## 팁
홍어·세발낙지 등 지역 음식 코스 연계. 강풍 시 케이블카 운행 확인.
