# 순천만습지·국가정원

| 항목 | 내용 |
|---|---|
| 소재지 | 전남 순천시 (국가정원: 국가정원1호길 47 / 습지: 순천만길 513-25 대대동, 자료별 표기 상이) |
| 분류 | 습지·정원 |
| 추천 시기 | 가을(갈대) |
| 운영시간 | 국가정원 3~4월·10월 08:30~19:00, 5~9월 ~20:00, 11~2월 ~18:00 / 습지 3~10월 08:00~20:00, 11~2월 ~19:00 (일부 자료와 상이, 2026-10 기준, 공식 확인 필요) |
| 요금 | 통합권 성인 15,000원·청소년 12,000원·어린이 8,000원, 만 6세 이하·65세 이상 무료 (블로그 1곳, 다른 자료는 10,000원으로 상이, 공식 확인 필요) |
| 휴무·예약 | 휴무일 자료 불확실(미확인), 예약 불필요로 보이나 미확인. 스카이큐브·생태체험선은 별도 요금 |

## 볼거리
- 갈대밭과 S자 수로, 용산전망대(2025-07-11 새 단장 개방)
- 순천만국가정원, 스카이큐브(별도 탑승권)
- 칠면초 군락, 낙조, 흑두루미 도래지

## 계절별 포인트
- 가을: 갈대 군락·칠면초 / 겨울: 흑두루미 (전망대 소개 기사)

## 가는 법
대중교통·주차 요점은 미확인. 문의: 국가정원 061-749-3114, 습지 061-749-6074 (자료 기재).

## 주변 연계 코스
- 낙안읍성, 보성 녹차밭 (에코투어 가이드 글 기준)

## 팁
- 세계유산 '한국의 갯벌'은 2021-07 보성-순천갯벌 등재(4개 갯벌). 2026-07 제48차 위원회에서 여수·고흥·무안·서산 추가 확장 승인, 순천만은 보성-순천-여수-고흥 구성요소(기사 보도 기준).
- 야간권은 습지 입장 불가.
