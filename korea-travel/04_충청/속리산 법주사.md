# 속리산 법주사

| 항목 | 내용 |
|---|---|
| 소재지 | 충북 보은군 속리산면 (정확한 도로명주소 미확인) |
| 분류 | 산사(유네스코 산사, 2018) |
| 추천 시기 | 가을 |
| 운영·요금 | 관람료: 2016년 4,000원, 2023년 사찰 관람료 폐지 추진 보도. 현재 징수 여부·주차료 미확인, 공식 확인 필요 (2026-10 기준) |
| 예약 | 미확인 |

## 볼거리
- 법주사: 553년 창건, 국보 3점 포함 문화재, 팔상전, 청동 미륵대불, 쌍사자석등(국보 제5호)
- 정이품송(천연기념물 제103호): 법주사 가는 길가
- 문장대: 세심정에서 왕복 약 6.6km, 3시간 30분(출발점에 따라 상이)

## 계절별 포인트
- 가을: 단풍. 가을 산불 예방 입산통제(11.15~12.15 사이 가능성)와 샛길·임산물 단속 안내 있어 사전 확인

## 가는 법
- 주차: 단풍철 주말 혼잡. 대중교통 노선 미확인

## 주변 연계 코스
- 서원리 소나무(정이품송의 부인으로 불림), 속리산테마파크(말티재, 월요일 정기 휴무 안내·요금은 오래된 자료)

## 팁
- 야간산행은 일몰 후~일출 2시간 전 제한(허가 시 가능). 입산 통제는 속리산국립공원사무소에 확인
