# 공주·부여 백제역사유적지구

| 항목 | 내용 |
|---|---|
| 소재지 | 공산성: 공주시 웅진로 280 / 무령왕릉(송산리고분군): 공주시 왕릉로 37-2 / 부소산성·정림사지: 부여군 |
| 분류 | 유네스코 세계유산(2015) |
| 추천 시기 | 봄·가을 (백제문화제 시즌 포함, 일정은 공식 확인) |
| 운영·요금 | 공산성·무령왕릉 09:00~18:00(3~10월), 09:00~17:00(11~2월), 마감 30분 전 입장. 개인 성인 3,000원 안팎(2026-10 기준, 공식 확인 필요). 통합권(무령왕릉·공산성 등)은 자료 오래됨, 미확인 |
| 휴무 | 설·추석 당일. 1월 1일 휴무 여부는 자료별로 상이, 공식 확인 필요 |
| 예약 | 개별 관람 예약 불필요로 보이나 미확인 |

## 볼거리
- 공산성: 웅진백제 산성, 한국어 해설 10:00~16:00 정시(동절기 15:00까지)
- 무령왕릉과 왕릉원(송산리고분군)
- 정림사지(5층석탑), 부소산성(낙화암·고란사 포함 입장료 안내 있음, 금액 미확인)

## 계절별 포인트
- 봄·가을: 성곽 산책과 단풍 (백제문화제는 가을 개최로 알려져 있으나 올해 일정 미확인)

## 가는 법
- 자차: 두 도시 하루 가능. 공산성-무령왕릉 약 815m(자차 2분, 블로그 기준)
- 대중교통: 공주 시외버스터미널 등에서 시내버스 노선은 미확인(지도앱 확인)

## 주변 연계 코스
- 공주: 공산성 - 무령왕릉 - 공주한옥마을 / 부여: 정림사지 - 사비길 - 부소산성

## 팁
- 정림사지는 무료, 운영시간은 자료별로 상이(18시 vs 22시), 공식 확인 필요. 부소산성 문의 041-830-2880(자료 기준)
