# 대전

| 항목 | 내용 |
|---|---|
| 소재지 | 대전광역시 (성심당 본점: 중구 대종로480번길 15, 다수 자료 일치) |
| 분류 | 도시·먹거리 |
| 추천 시기 | 사계절 (장태산 메타세쿼이아는 가을) |
| 운영·요금 | 성심당 본점 08:00~22:00 연중무휴로 안내하는 자료 있음, 다른 시간 표기 자료도 있어 자료별로 상이, 공식 확인 필요. 한빛탑 09:30~17:40, 월요일·1/1·설추석 휴무, 무료로 안내(자료 1곳, 마감 표기 불일치). 장태산자연휴양림 입장 무료·연중무휴(2025 게시물 기준) (2026-10 기준, 공식 확인 필요) |
| 예약 | 성심당 예약 불필요(대기 발생). 숙박·야영 시설은 별도 예약 |

## 볼거리
- 성심당: 인기 빵은 대기, 전 매장 임시 휴무 사례 있음(2025-11-03 사내 행사)
- 엑스포 한빛탑(엑스포과학공원, 문의 042-250-1111)
- 장태산자연휴양림: 출렁다리·하늘길, 메타세쿼이아 숲

## 계절별 포인트
- 가을: 장태산 단풍철 주말 교통 통제·주차 혼잡 가능, 이른 오전 방문 권장
- 겨울: 장태산 동절기 단축 운영 가능

## 가는 법
- KTX 대전역 접근. 성심당 본점·한빛탑·장태산 간 노선은 미확인

## 주변 연계 코스
- 대전역 - 성심당 본점 - 으능정이 거리(성심당문화원은 별도 시설)

## 팁
- 방문 전 성심당 공식 SNS·고객센터 1588-8069(자료 기준)로 당일 영업 확인
