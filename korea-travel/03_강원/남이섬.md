# 남이섬

| 항목 | 내용 |
|---|---|
| 소재지 | 강원 춘천시 남산면 남이섬길 1 (섬). 배 타는 선착장은 경기 가평군 가평읍 북한강변로 1024 |
| 분류 | 섬·산책 |
| 추천 시기 | 가을 |
| 가는 법 | 가평 선착장에서 배 이동. 내비게이션에는 선착장 주소 입력 |
| 운영·요금 | 입장료에 왕복 선박 포함, 성인 19,000원(일반선박 기준) / 첫 배 08:00, 마지막 입도 21:00(추계 9.18~11.22는 07:30~21:30, 금·토·일·공휴일) (2026-10 기준, 공식 확인 필요). 자료별로 요금·시간 상이(구자료 16,000원 등) |
| 예약 | 온라인 예약 가능(공식 사이트 예약 메뉴). 필수 여부는 미확인 |

## 볼거리
- 메타세쿼이아 길, 은행나무 길
- 선착장에서 배로 이동(모터보트는 4~11월경 시즌 운영)
- 반려견 동반 안내 페이지 별도 운영(조건은 공식 확인)

## 계절별 포인트
- 가을: 단풍 시즌에 맞춰 운항 시간 연장(위 표 참조)

## 가는 법
- 주소상 춘천이지만 입구는 가평 선착장. 대중교통·주차 상세는 미확인(공식 확인 필요).

## 주변 연계 코스
미확인(공식 확인 필요).

## 팁
- 시간은 상황에 따라 변동, 문의 031-580-8114. 한 예매 사이트는 방문 1시간 전 구매를 안내.
