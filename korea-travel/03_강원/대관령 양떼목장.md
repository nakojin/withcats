# 대관령 양떼목장

| 항목 | 내용 |
|---|---|
| 소재지 | 강원 평창군 대관령면 대관령마루길 483-32 (자료 기재 기준) |
| 분류 | 목장·초원 |
| 추천 시기 | 여름 초록·겨울 설경 |
| 가는 법 | 대중교통 미확인. 주차는 블로그에서 무료라고 했으나 미확인(공식 확인 필요) |
| 운영·요금 | 2024-05-01부터 성인 9,000원·소인 7,000원·우대 6,000원(공식 공지). 36개월 미만 무료. 매표 09:00~17:30 표기, 월별 시간·현재 요금 자료별 상이(2026-10 기준 미확인, 공식 확인 필요) |
| 예약 | 사전 예약 시 할인된다는 블로그 정보 있으나 미확인 |

## 볼거리
- 초원 산책로(약 1.2km), 끝에 건초 주기 체험장(체험 1,000원, 블로그 기준)
- 양은 5월 중순~10월 말 방목, 겨울엔 축사 생활

## 계절별 포인트
- 여름: 초록 초원(고지대라 바람 강함)
- 겨울: 설경. 방목된 양은 보기 어려울 수 있음

## 가는 법
- 공식 사이트 yangtte.co.kr 확인. 상세 교통은 미확인.

## 주변 연계 코스
미확인. 대관령 하늘목장은 별개 시설이니 혼동 주의.

## 팁
- 겉옷 준비. 휴무일 미확인.
