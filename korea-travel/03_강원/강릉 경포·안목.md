# 강릉 경포·안목

| 항목 | 내용 |
|---|---|
| 소재지 | 강원 강릉시 (경포대 경포로 365, 오죽헌 율곡로3139번길 24, 안목 커피거리 창해로14번길 일대) |
| 분류 | 바다·커피 |
| 추천 시기 | 여름·사계절 |
| 가는 법 | KTX 강릉역 접근 양호(기존 내용). 구간별 버스·주차 미확인 |
| 운영·요금 | 오죽헌: 매표·입장 17:00 마감, 연중무휴(1/1·설·추석 당일은 오죽헌만 개방, 실내 전시실 휴관) (2024 공연 안내 페이지 기준, 공식 확인 필요). 오죽헌 요금·경포대 시간 미확인 |
| 예약 | 미확인 |

## 볼거리
- 경포대·경포호·경포해변. 지정 종류는 자료별로 상이(보물 2046호 / 명승 108호 언급), 국가유산포털 확인 필요
- 안목 커피거리: 강릉항~안목해맞이공원 약 516m(자료 기준)
- 오죽헌: 보물 제165호(1963-01-21 지정), 율곡 이이 탄생지, 천연기념물 율곡매

## 계절별 포인트
- 봄: 경포 벚꽃축제(2026 기사). 여름: 해변. 그 외 미확인

## 가는 법
- 위 표 참조.

## 주변 연계 코스
- 경포대·오죽헌·안목은 같은 강릉 권역(구체 동선 미확인)

## 팁
- 카페 영업시간·휴무는 점포마다 상이. 내비게이션에는 강릉항 또는 안목해변 검색.
