# 추암 촛대바위

| 항목 | 내용 |
|---|---|
| 소재지 | 강원 동해시 촛대바위길 (번지 26/28 자료별 상이, 공식 확인 필요) |
| 분류 | 해안·일출 |
| 추천 시기 | 새벽 일출 |
| 가는 법 | KTX 동해역에서 택시 약 10분, 시내버스 61번(블로그). 무료 공영주차장(블로그) |
| 운영·요금 | 입장 무료(기사 기준). 출렁다리 시간은 09:00~20:00 / 하절기 09:00~22:00·동절기 09:00~20:00 등 자료별 상이, 악천후 통제 (2026-10 기준, 공식 확인 필요) |
| 예약 | 불필요(미확인) |

## 볼거리
- 촛대바위(능파대 일대, 척주팔경의 하나)
- 추암 출렁다리(2019-06 신설, 길이 72m, 해상 출렁다리). 다리 끝은 추암 조각공원
- 해암정(고려 말 심동로 건립 전해짐, 현 건물 중수). 지정 번호는 자료로 미확정

## 계절별 포인트
- 일출 명소, 사계절 방문. 시각은 계절별 상이(겨울 7시 30분 전후, 블로그)

## 가는 법
- 위 표 참조. 문의 추암관광안내소 033-530-2801.

## 주변 연계 코스
- 해파랑길 33코스(추암해변~묵호역)

## 팁
- 촛대바위는 가파른 계단, 출렁다리는 완만한 경사로(휠체어·유모차 가능, 관광공사).
