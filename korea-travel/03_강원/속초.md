# 속초

| 항목 | 내용 |
|---|---|
| 소재지 | 강원 속초시 (아바이마을 청호로 122, 영금정 영금정로 43) |
| 분류 | 항구·시장 |
| 추천 시기 | 사계절 |
| 가는 법 | 시장에서 갯배 선착장까지 도보 10분 이내(자료 기준). 대중교통·주차 미확인 |
| 운영·요금 | 갯배 편도 대인 500원·소인 300원(속초 주민 무료), 운행시간 자료별 상이(04:30~23:00 등). 영금정 상시 개방. 시장 08:00~21:00 또는 24:00 등 상이 (2026-10 기준, 공식 확인 필요) |
| 예약 | 불필요(미확인) |

## 볼거리
- 속초관광수산시장(구 속초중앙시장): 닭강정·오징어순대 등, 야시장 있음(계절별 상이)
- 아바이마을(갯배 약 5분, 아바이순대)
- 영금정

## 계절별 포인트
확인된 계절 정보 없음.

## 가는 법
미확인(공식 확인 필요). 문의: 속초시청 관광과 033-633-3171 / 033-639-2713(자료별 상이).

## 주변 연계 코스
- 시장 → 아바이마을 → 영금정(아바이마을에서 도보 약 15분, 블로그) / 영랑호·설악산

## 팁
- 점심시간 혼잡, 11시 이전·14시 이후 권장(일부 의견). 휠체어는 갯배 승하선 시 도움 필요.
