# 설악산

| 항목 | 내용 |
|---|---|
| 소재지 | 강원 속초·양양·인제 (외설악 입구 설악동: 설악산국립공원사무소 속초시 설악산로 833) |
| 분류 | 국립공원(유네스코 생물권보전지역) |
| 추천 시기 | 10월 단풍 |
| 가는 법 | 설악동 소공원 기점(주소 설악산로 1091, 소공원 주차장 설악산로 1032, 국립공원공단 안내). 케이블카는 신흥사 유료 주차장 이용(블로그 기준) |
| 운영·요금 | 국립공원 입장료 무료(2023-05 시행). 케이블카 요금·시간 미확인(기상에 따라 변동) |
| 예약 | 설악케이블카는 현장 발권·왕복만(블로그 기준). 울산바위 예약제 미확인 |

## 볼거리
- 울산바위(소공원에서 왕복 약 3~4시간, 자료별 상이), 권금성(케이블카), 대청봉

## 계절별 포인트
- 가을: 단풍철 케이블카 1시간 이상 대기 가능(블로그). 단풍 절정 시기는 미확인

## 가는 법
- 외설악 소공원 기점 위 참조. 대중교통 상세 미확인.

## 주변 연계 코스
- 신흥사(속초시 설악산로 1137), 속초 시내(별도 문서)

## 팁
- 입산시간지정제 적용 구간(2026-06-22 변경 공고 있음), 봄철 산불예방기간·기상특보 시 통제. 최신 확인 필수. 문의 033-801-0900.
