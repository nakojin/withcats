# 성산일출봉

| 항목 | 내용 |
|---|---|
| 소재지 | 제주특별자치도 서귀포시 성산읍 일출로 284-12 |
| 분류 | 유네스코 세계자연유산(2007, '제주 화산섬과 용암동굴'), 천연기념물 제420호(2000) |
| 추천 시기 | 새벽 일출(연중). 겨울은 날씨로 일출을 못 볼 수 있음 |
| 가는 법 | 버스 '성산일출봉입구[서]' 정류장 하차. 성산일출봉주차장 이용(입구까지 약 100m) |
| 운영·요금 | 3~4·9~10월 05:00~19:00 / 5~8월 04:30~20:00 / 11~2월 06:00~18:00, 매표는 마감 1시간 전. 성인 5,000원, 청소년·군인·어린이 2,500원 (2026-10 기준, 공식 확인 필요) |
| 휴무·예약 | 매월 첫째 주 월요일(공휴일이면 다음 날). 예약: 확인된 사전예약 안내 없음(미확인) |

## 볼거리
- 정상 분화구(지름 약 600m, 자료상), 해안 절벽, 영주십경 '성산일출'
- 얕은 바다에서 폭발해 생긴 수성화산체. 정상까지 계단으로 약 30~40분

## 계절별 포인트
- 새벽 일출이 핵심. 12월 31일 성산일출축제 언급 자료 있음(올해 일정 미확인)

## 가는 법
- 제주시에서 함덕·김녕 경유 성산행 버스. 서귀포에서도 성산 경유 버스 운행(노선 번호는 공식 확인)

## 주변 연계 코스
- 광치기해변(일출 대기·조망), 섭지코지, 우도(성산포항 배편)

## 팁
- 음식물 반입 금지. 우뭇개해안 쪽 무료 탐방구간도 있음. 문의 064-783-0959
- 기존 문서의 '서귀포'는 정확히 서귀포시 성산읍
