# 우도

| 항목 | 내용 |
|---|---|
| 소재지 | 제주특별자치도 제주시 우도면 (우도해양도립공원) |
| 분류 | 섬, 해양도립공원 |
| 추천 시기 | 봄~여름(미확정, 기존 유지). 둘레 약 17km |
| 가는 법 | 성산포항(성산항) 또는 종달항에서 배 약 10~15분. 성산포항까지 제주시 111·101번 급행, 서귀포 201·501번 등 버스(자료상) |
| 운영·요금 | 배 운임+도립공원료를 함께 결제. 성산항 첫 배 8시경, 막배 17:30~18:30 자료별 상이. 왕복 운임도 자료별 상이(5,500원~11,000원대) → 선사 확인 (2026-10 기준, 공식 확인 필요) |
| 예약 | 승선권은 현장 구매 위주(블로그 설명), 신분증 지참·승선신고서 작성 |

## 볼거리
- 서빈백사(홍조단괴해빈, 천연기념물), 우도봉(성산일출봉 조망)
- 전기차·자전거 일주(3~4시간 소요, 자료상)

## 계절별 포인트
- 확인된 계절 정보 부족(미확인)

## 가는 법
- 성산포항 종합여객터미널 064-782-5671. 종달항 시간표·운임은 미확인
- 외부 차량 반입 제한이 2026-08-01~2029-07-31 연장(예외: 저공해 렌터카, 숙박객 등 조건부)

## 주변 연계 코스
- 성산일출봉, 광치기해변, 섭지코지

## 팁
- 풍랑 시 결항 잦음. 도립공원 입장료 어른 1,000원 등은 자료 1곳 근거(공식 확인)
- 기존 '제주시'는 정확히 제주시 우도면
