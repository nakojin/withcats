# 천지연폭포

| 항목 | 내용 |
|---|---|
| 소재지 | 제주특별자치도 서귀포시 (도로명 '남성중로 2-15' 표기가 있으나 단일 자료, 공식 확인 필요) |
| 분류 | 폭포 |
| 추천 시기 | 사계절. 야간 조명 관람 가능 |
| 가는 법 | 무료 주차 안내(블로그), 버스 정보 미확인 |
| 운영·요금 | 09:00~22:00(입장 마감 21:20). 성인 2,000원, 청소년·어린이 1,000원. 6세 이하·65세 이상·제주도민 등 무료(신분증) (2026-10 기준, 공식 확인 필요) |
| 예약 | 불필요(무인 발권기 있음) |

## 볼거리
- 천지연폭포, 야간 조명(2026-05-11 42년 만에 조명 교체 후 야간 관람 재개)
- 새연교, 이중섭거리는 인근(기존 내용, 거리는 미확인)

## 계절별 포인트
- 확인된 계절별 정보 없음(미확인)

## 가는 법
- 서귀포시 E-Ticket 안내 참조. 대중교통 노선은 미확인

## 주변 연계 코스
- 새연교, 이중섭거리, 천제연폭포(별개 폭포, 서귀포 E-Ticket에 따로 안내)

## 팁
- 야간 무료는 재개장 첫날 한정이었음. 시간·요금은 서귀포 E-Ticket 확인
- 일부 자료는 요금 표기가 서로 다름(공식 기준 우선)
