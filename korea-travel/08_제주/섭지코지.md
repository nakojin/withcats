# 섭지코지

| 항목 | 내용 |
|---|---|
| 소재지 | 제주특별자치도 서귀포시 성산읍 섭지코지로 262 (행정리명은 고성리/신양리 자료별 상이) |
| 분류 | 해안(곶) |
| 추천 시기 | 봄(유채꽃, 3월 전후 자료상) |
| 가는 법 | 내비는 '섭지코지'로 검색. 대중교통 미확인 |
| 운영·요금 | 상시 개방·입장 무료. 주차 소형 최초 30분 1,000원, 이후 15분마다 500원, 1일 최대 3,000원 (자료 1곳, 2026-10 기준, 공식 확인 필요) |
| 예약 | 불필요 |

## 볼거리
- 등대(철계단으로 올라 해안 전망), 선돌, 유채꽃밭, 해안 산책로(약 1.2km, 약 1시간)
- 글라스하우스(안도 다다오 설계, 카페 10:00~19:00, 문의 064-731-7001, 변동 가능)

## 계절별 포인트
- 봄: 유채꽃. 개화 시기는 해마다 변동

## 가는 법
- 글라스하우스 주차는 불가 안내(영문), 섭지코지 공영주차장 이용

## 주변 연계 코스
- 성산일출봉, 광치기해변, 우도(성산포항)

## 팁
- 바람 강함. 문의 064-784-2810
- 휘닉스 아일랜드 주차장 1일 5,000원 안내도 있음
