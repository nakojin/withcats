# 만장굴

| 항목 | 내용 |
|---|---|
| 소재지 | 제주특별자치도 제주시 구좌읍 만장굴길 182 (김녕리) |
| 분류 | 용암동굴. 천연기념물 제98호('김녕굴과 만장굴'), 유네스코 세계자연유산(2007) |
| 추천 시기 | 사계절(동굴 내부 서늘) |
| 가는 법 | 주차 무료(대형 60·소형 75대, 비짓제주). 버스 미확인 |
| 운영·요금 | 09:00~18:00, 입장 마감 17:00 또는 17:10(자료별 상이). 일반 4,000원, 청소년·어린이 2,000원, 경로·장애인 무료 (2026-10 기준, 공식 확인 필요) |
| 휴무·예약 | 매월 첫째 수요일 휴무. 예약 안내 미확인. 문의 064-710-7903 |

## 볼거리
- 총길이 약 7.4km 중 제2입구부터 약 1km만 개방
- 용암석주(기존 내용, 이번 조사에서 미확인)

## 계절별 포인트
- 계절별 정보 미확인(내부 서늘함은 기존 내용)

## 가는 법
- 제주시 구좌읍 김녕리 일대. 내비에 '만장굴길 182' 입력

## 주변 연계 코스
- 김녕해수욕장 일대는 미확인. 김녕사굴은 출입 금지라 관람 불가(자료상)

## 팁
- 낙석으로 2년 넘게 휴장 후 2026-05-30 재개방. 이후 운영 변동 공지 확인
- 랜턴·운동화·보온 겉옷 권장. 해설사 해설 무료(자료상 09:00~17:00)
- 지정일은 자료별 상이(1962-12-03 vs 12-07)
