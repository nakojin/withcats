## 선정 범위

중국 전역을 골고루 나열하기보다 한국 여행업계 자료에서 수요가 확인되는 도시·여행권역을 우선했습니다. 한국인 전체의 인기순위가 아니며 개별 내부 명소의 인기까지 입증하지 않습니다. 핵심 수요지역, 여행 동선상 연계확장, 근거가 제한적인 후보를 구분합니다. 조사기간·업체·표본·한계와 출처는 [선정 근거](selection-rationale.md)를 읽으세요. 중국 본토 중심으로, 홍콩·마카오 등 별도 입경 지역은 포함하지 않았습니다.

## 이용 방법

- index.html: 압축을 풀고 브라우저로 열면 이름·본문 검색과 권역·성/직할시·선정구분·운영상태 필터를 인터넷 없이 사용할 수 있습니다. 외부 출처 방문에는 인터넷이 필요합니다.
- catalog.json: 통합 구조화 자료. items 배열의 레코드를 사용하세요.
- places/: 관광지별 설명, 볼거리, 추천 시기와 이유, 방문 팁, 운영조건, 출처와 미확인 사항.
- regions/: 권역별 목차.
- selection-rationale.md/json: 수요 근거, 기간과 표본, 선정 구분.
- validation-report.json: 수량, 중복, 상하위 관계, 필수필드·출처·날짜·링크·오프라인 동작 검사.
- source-research/: 원본 조사자료. 최종 catalog에 적용한 명칭·관계 정규화는 검증 보고서에서 확인하세요.

## 사실 확인과 한계

공식 본문 열람과 최신 운영정보 검증은 별개입니다. 직접 열람 여부는 조사 담당 기록에 근거하며 일부만 추가 대조되었습니다. 검색 결과 요약만 확인한 출처는 본문 열람으로 세지 않습니다. 가격·시간·예약·교통·공사·휴관·기상은 방문 직전 확인하세요. 중국 내국인 신분증 기준 예약을 외국인 여권에도 가능하다고 일반화하지 않습니다. 여권·해외 전화번호·결제수단·현장 발권 지원은 확인된 경우만 명시했습니다. 계절 추천과 동선 팁에는 편집적 조언이 포함됩니다.

상위 풍경구·지구와 내부 명소는 parent_id로 연결했습니다. 양강사호·상산과 백두산 중국 측은 별도 관광지 레코드를 추가하지 않고 집계용 상위그룹(grouping_containers)으로만 정의했습니다. 연구 레코드는 읽기 편의를 위한 설명 단위이며 독립 목적지 수와 다릅니다. 휴관 레코드는 조사자료로 보존하고 추천 검토 대상에서 제외했습니다. 나머지 항목도 실시간 개방을 보장하지 않습니다.

지도 좌표, 사진 사용권, 실시간 교통·예약·가격은 제공하지 않습니다. 오프라인 JavaScript 필터와 링크는 자동 검사하며 실제 브라우저 화면의 시각적 렌더링은 미검증입니다. 외부 게시·업로드는 이 조립 작업 범위에 포함하지 않았습니다.
