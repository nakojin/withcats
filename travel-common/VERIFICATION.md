# 자료 검증 절차 (v2)

실제 여행 가이드로 쓰는 자료라서 **수집과 검증을 분리**한다. 이 절차를 통과한 값만 공개 데이터(`published`)에 들어간다.

## 1. 역할 분리

| 단계 | 담당 | 하는 일 | 하지 않는 일 |
|---|---|---|---|
| 수집 | 수집 에이전트 (Sonnet 5.5) | 공식·1차 출처를 찾아 사실을 원자 단위 `claim` 으로 뽑고, 각 claim 에 출처 URL·확인일을 붙인다 | 공개 데이터 수정, 추정값 기입 |
| 검증 | 검증 에이전트 (Opus 5.5) | 수집과 **독립적으로** 출처를 다시 열어 claim 마다 판정한다 | 새 claim 추가(누락은 보고만) |
| 병합 | 메인 세션 | 판정이 `verified` 인 claim 만 레코드에 반영하고 검증기(`tools/validate_v2.py`)를 통과시킨다 | 판정 없이 반영 |

수집자와 검증자는 같은 모델·같은 실행을 쓰지 않는다. 검증자는 수집자의 결론을 받지 않고 claim 과 출처 URL 만 받는다.

## 2. claim 형식

```
{ "field": "ops.fees | ops.hours | ops.reservation | ops.closed_days | ops.payment | location | description | highlight | duration | access | tip",
  "text": "우리 문장으로 쓴 사실 한 개",
  "value": "수치·시간이 있으면 정규화한 값",
  "sources": [{"url": "...", "type": "official | government | national_tourism | operator | secondary", "checked_at": "YYYY-MM-DD"}] }
```

## 3. 출처 등급과 필요 조건

| 항목 | 필요한 출처 |
|---|---|
| 요금·운영시간·예약·휴무·결제 | 운영자 공식 또는 관리 기관 1곳 **필수**. 공식이 둘 이상이면 서로 대조 |
| 위치·주소·좌표 | 공식 주소 1곳 + 좌표는 OSM 등 지도와 대조(거리 차 500m 이내) |
| 역사·규모·수치(연도, 높이, 길이) | 공식 또는 정부·국가관광기관 1곳 |
| 설명·하이라이트 | 공식 또는 국가관광기관. 문장은 복제하지 않고 요약 |
| 소요시간·접근 | 공식 안내 우선. 없으면 `secondary` 2곳이 일치할 때만, `basis: secondary` 표시 |
| 평점·리뷰 지표 | 참고 지표로만. 출처·확인일 필수, 본문 사실 근거로 쓰지 않음 |

블로그·여행사 홍보 글은 출처를 찾는 단서로만 쓰고 근거로 삼지 않는다.

## 4. 판정

| 판정 | 뜻 | 처리 |
|---|---|---|
| `verified` | 검증자가 출처를 직접 열어 일치 확인 | 반영 |
| `corrected` | 출처와 다름. 검증자가 출처 기준 값 제시 | 수정값 반영, 변경 기록 |
| `outdated` | 과거엔 맞았으나 현재 다름 | 현재값 반영 |
| `unverifiable` | 출처를 열 수 없거나 근거 없음 | **공개 데이터에서 제외**, `unconfirmed` 로 이유 기록 |
| `rejected` | 출처가 1차 출처 요건 미달 | 제외 |

## 5. 품질 기준 (릴리스 게이트)

- Tier A 레코드: 요금·운영시간·위치 claim 은 100% `verified/corrected/outdated` 이거나 `not_applicable`.
- 표본 재검증: 릴리스 전 무작위 10% 를 별도 검증자가 다시 확인해 오류율 2% 이하.
- 확인일 90일 경과 시 사이트에 재확인 표시. 180일 경과 시 운영값 비공개.
- 모든 변경은 `changes/` 에 레코드별 이전값·새값·근거를 남긴다.

## 6. 가이드 필수 항목 (2026-10-11 감사 반영)

표본 감사에서 사실 오류는 0건이었지만 누락이 가장 큰 문제였다. Tier A 레코드는 아래 항목마다 **값** 또는 **확인 불가 이유**를 반드시 가진다. 빈칸으로 두지 않는다.

| 항목 | 내용 |
|---|---|
| 위치 | 도로명 주소, 행정구역(최신 명칭) |
| 접근 | 가장 가까운 역·정류장, 도보·차량 시간, 주차 여부·요금 |
| 소요시간 | 공식 안내 우선. 없으면 `basis: secondary` |
| 운영시간·휴무 | 계절별 시간, 마지막 입장, 정기 휴무 |
| 요금 | 성인·어린이·할인·무료 대상. **무료면 "무료"로 명시하고 근거를 단다** (null 금지) |
| 예약 | 사전 예약 여부, 창구, 오픈 시점. 중국은 실명·여권 처리 |
| 결제 | 현금·카드·모바일 결제(중국은 알리페이·위챗페이) |
| 언어 | 한국어 안내·오디오가이드 유무 |
| 주의 | 안전, 금지 사항, 혼잡 시기 |

추가 규칙:

- **인용한 출처에 있는 정보는 빠뜨리지 않는다.** 수집자는 출처 페이지의 운영 정보를 모두 claim 으로 뽑는다.
- **출처 갱신일**을 함께 기록한다. 페이지가 12개월 이상 갱신되지 않았으면 `stale_source` 로 표시하고 다른 공식 출처를 찾는다.
- **행정구역 변경**(예: 전남광주통합특별시, 인천 제물포구)은 최신 공식 표기를 따르고, 이전 표기는 `former_region` 으로 남긴다.
- WebFetch 가 503 을 돌려주면 curl 로 다시 열어 본다. 둘 다 실패하면 `unverifiable`.
