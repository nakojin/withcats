# Tier A 후보 조사 근거

2026-10-10 웹검색으로 한국인이 많이 찾는 일본·중국 지역·명소와 한국 대표 관광지를 조사한 원본이다. 사실·수치만 요약했고 기사·리뷰 문장은 옮기지 않았다. 각 항목에 근거 URL과 연도가 있다.

| 파일 | 내용 |
|---|---|
| `research_kr.json` | 한국 명소 82건 (시도별) |
| `research_jp.json` | 일본 지역 30곳, 명소 96건 |
| `research_cn.json` | 중국 지역 23곳, 명소 73건 |

`notes` 필드에 조사의 한계와 출처 간 충돌을 적었다. 선정 결과는 `../tiers/` 를 본다.
