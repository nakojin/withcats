### 💻 코냥 1차 실무

💻 코냥: 작업 시작합니다.

- **데이터 수집 방법**:
  - 네이버 Open API 또는 공식 검색 API를 사용하여 PWA 관련 키워드 검색.
  - API 요청에 필요한 Client ID / Client Secret은 환경 변수에 저장.

- **API 연동 시 필요한 키 데이터 및 항목**:
  - `client_id`: API 인증용 클라이언트 ID
  - `client_secret`: API 인증용 클라이언트 Client Secret 또는 API 토큰

- **수집 데이터 저장 구조**:
  - JSON 파일로 저장, 각 항목은 PWA 관련 키워드와 해당 키워드의 검색 결과 URL.

- **자동화 구현 방법**:
  - Next.js 라우팅을 이용하여 API 요청 및 결과 표시.
  - Puppeteer를 사용하여 페이지 스크래핑 (권한이 있는 사이
- Puppeteer, 크롤링, 스크래핑은 권한이 있는 사이트와 약관이 허용하는 범위에서만 사용하며, robots.txt와 서비스 정책 확인 후 진행합니다.



### 📺 기획냥 1차 실무

1. **유튜브 채널 분석**: 현재 트렌드를 파악하여 관련성 있는 콘텐츠를 선정합니다.
2. **콘텐츠 기획서 작성**: 제목, 후크, 구조를 포함한 콘텐츠 계획을 세웁니다.
3. **썸네일 브리프 및 메타데이터 작성**: 흥미롭고 매력적인 썸네일과 업로드 메타데이터를 준비합니다.
4. **자동화 기능 수립**: 유튜브 API와 연동하여 자동으로 콘텐츠를 생성하고 게시하는 기능을 구축합니다.
