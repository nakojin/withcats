## 🧠 🧭 팀장냥 수석 PM의 정제 요약본 (Purified Summary)

> [!NOTE]
> 이 문서는 실제 검색 결과가 아니라 조사 설계/전략 프레임 정제 요약본입니다. 원문 회의록 전체가 아닌 안전하게 정리한 요약만 포함합니다냥. 🐾

### 1. 요청 범위

- 사용자 요청은 "유튜브 뷰티 채널 인기 주제 10개 조사해서 콘텐츠 전략 세워줘"에 대한 유튜브 콘텐츠 전략 수립입니다.
- 현재 단계에서는 확정 데이터처럼 단정하지 않고, YouTube Data API 또는 권한 있는 분석 커넥터 전의 실행 프레임만 정리합니다.

### 2. 역할별 정제 요약

- 리서냥은 조사 기준, 후보 지표, 검증 필요성을 정리했습니다.
- 작가냥은 제목 전략, 글 구조, 예시 후보의 사용 범위를 정리했습니다.

### 3. 조사 설계 프레임

- YouTube Data API 또는 권한 있는 분석 커넥터에서 제공되거나 내부적으로 검토 가능한 항목을 먼저 확인합니다.
- 기본 검토 항목은 채널명, 영상 제목, 게시일, 설명, 태그, 조회수 후보 지표, 좋아요 수 후보 지표, 댓글 수 후보 지표입니다.
- 키워드 연관성, 최신성, 콘텐츠 유형을 기준으로 후보를 선별합니다.

### 4. 유튜브 콘텐츠 전략 수립

- 유튜브 콘텐츠에 맞는 전략은 질문형, 문제해결형, 체크리스트형으로 나눕니다.
- 구조는 도입 문제 제기 → 핵심 리스트 → 적용 팁 → 다음 행동 제안 순서로 구성합니다.
- 예시 후보는 전략 수립용 예시로만 다루며, 확정 목록은 YouTube Data API 또는 권한 있는 분석 커넥터 후 별도로 검증합니다.

### 5. 안전한 자동화 방향

- 기본 방향은 YouTube Data API 또는 권한 있는 분석 커넥터입니다.
- 필요 시 권한 있는 웹검색 커넥터를 사용하고, 수집 가능 여부 확인 후 자동화합니다.
- Puppeteer, 크롤링, 스크래핑은 권한이 있는 사이트와 약관이 허용하는 범위에서만 사용하며, robots.txt와 서비스 정책 확인 후 진행합니다.
