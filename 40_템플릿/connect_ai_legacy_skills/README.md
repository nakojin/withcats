# 🎓 레거시 에이전트 스킬 작동 및 구축 가이드 (Legacy Skills Guide)

> [!NOTE]
> 본 문서는 레거시 Connect AI 로컬 저장소(`C:\Users\nakojin\.connect-ai-brain`) 내 각 에이전트 폴더 아래 존재했던 `skills/README.md` 파일들의 코어 설계 개념과 작동 방식을 통합하여 복구한 템플릿 가이드 문서입니다.
> 에이전트들이 반복적이고 일관된 결과물을 생산하도록 돕는 "스킬(Skill) 관리 파이프라인"을 이해하고 커스텀 스킬을 만드는 지침서로 활용할 수 있습니다.

---

## 1. 스킬(Skill) 이란?

* **정의**: 에이전트가 수행한 작업 중 검증되고 정제된 **재사용 가능한 프롬프트 패턴 및 작업 방식 모음**입니다.
* **차별성**: 
  * `memory.md`는 에이전트의 모든 실행 이력과 상호작용 로그를 누적하는 일방향 데이터 스트림(append-only firehose)입니다.
  * `skills/` 폴더 내의 각 템플릿(`.md`) 파일은 그 중 **가장 가치 있고 신뢰할 수 있는 모범 사례**만을 분리해 놓은 파일입니다.
* **주입 메커니즘**: 에이전트가 호출될 때, `skills/` 디렉토리에 있는 개별 `.md` 파일들이 **에이전트의 시스템 프롬프트(system prompt)에 동적으로 주입**되어 자율 가동의 정합성을 크게 높여줍니다. (단, 본 `README.md` 파일은 주입 대상에서 제외됩니다.)

---

## 2. 스킬 템플릿 규격 및 내용

각 에이전트는 역할에 특화된 스킬 형식을 가집니다. 대표적인 스킬 템플릿 구조는 다음과 같습니다:

```markdown
# [스킬명: 에이전트가 준수해야 할 정형 패턴]

## 1. 목적 및 상황
- 언제 이 스킬을 적용해야 하는지 명시합니다. (예: "블로그 카피라이팅을 검수할 때")

## 2. 모범 예시 (Best Practice)
- 가장 완벽하게 처리된 실제 입력과 출력의 예제를 수록합니다.

## 3. 예외 처리 및 금지 사항
- 절대로 수행해서는 안 되는 행동 양식이나 에러 패턴을 규정합니다.
```

## 3. 스킬을 추가하고 관리하는 3가지 방법

에이전트에게 새로운 스킬을 학습시키고 이관하는 방식은 매우 단순하고 자동화되어 있습니다:

### 1) 메신저 명령어를 통한 승격
* 에이전트와의 채팅창(예: 텔레그램 메신저 연동 환경)에서 `/skill` 또는 `/promote` 명령어를 입력하면, 방금 전 생성된 고품질의 산출물이 에이전트 스킬 폴더로 자동 승격 저장됩니다.

### 2) 개발 툴 연동 (VS Code / Cursor)
* VS Code 명령 팔레트(`Ctrl + Shift + P`)에서 `Connect AI: 방금 산출물 -> 스킬로 저장` 명령을 선택하면 에이전트 별 `skills/` 폴더에 즉시 반영됩니다.

### 3) 수동 생성 및 배치
* 에이전트의 스킬 디렉토리 하위에 직접 `<스킬명>.md` 형식의 파일을 생성한 뒤 마크다운 문법으로 핵심 프롬프트를 기재해 두면, 다음 루프 가동 시 에이전트가 이를 자율적으로 인지합니다.
