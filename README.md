# 🐈 withcats (Knowledge Vault)

`withcats`는 **야옹야옹 AI 스튜디오 (YaongYaong AI Studio)**의 핵심 지식 기반이자 상태 정보를 영구히 기록하는 **Knowledge Vault (지식 저장소)** 저장소입니다. 

엔진 및 소스 코드 저장소인 `yaongyaong_ai_studio`와 분리되어 운영되며, 에이전트들의 페르소나 설정, 주간/월간 목표, 축적된 기억(Memory), 전역 의사결정 장부, 그리고 모든 런타임 세션의 결과물(CEO 리포트 등)을 엄격하게 관리합니다.

---

## 📌 주요 폴더 및 파일 설명

* **`_company/`**: 에이전트 상태 및 의사결정의 핵심 영역입니다.
  * **`_agents/`**: 10마리의 고양이 캐릭터 에이전트별 프롬프트, 기억(`memory.md`), 개인 목표, 전용 도구 정보가 격리 캡슐화되어 있습니다.
  * **`_shared/`**: 전역 의사결정 장부(`decisions.md`), 회사 정체성 규정(`identity.md`), 500개 이상의 태스크 증적 장부(`tracker.json`) 등이 보관되는 센트럴 뱅크입니다.
  * **`sessions/`**: 매 사이클마다 구동된 상세 에이전트 업무 산출물 및 CEO 평가 리포트의 역사적 기록이 일자별로 보관됩니다.
* **`site/`**: 정적 사이트 포스트 산출물이 격리되어 독립 관리되는 영역입니다. (기존 `_company/site/`에서 이관 완료)
* **`00_Raw/`**: 외부 트렌드 정보, 유저가 제공한 기획서, 원본 원고 등 에이전트 지식 주입(RAG)용 원자료 보관 폴더입니다.
* **`40_템플릿/`**: 개발 에이전트(`developer`)가 프론트엔드 코드나 웹 화면을 설계할 때 복사·참조하여 사용하는 설계 골격 템플릿( landing-kit 등 ) 보관함입니다.
* **`company_state.json`**: 전체 완료 태스크 수, 주입 지식 수 등 스튜디오 전체 생명주기 지표를 담은 대시보드 상태 파일입니다.

## 🏛 구조 업그레이드 이정표 안내

저장소 구조의 비대화 예방, 코드와 데이터의 안전한 분리, 시스템 OS 이식성 향상을 위해 다음 단계의 차세대 폴더 구조 업그레이드(v2)가 예정되어 있습니다. 
상세한 구조 진단 분석 및 리팩토링 체크리스트는 아래 문서를 참고하십시오.

* **구조 개선 기준 청사진**: [docs/architecture_review.md](docs/architecture_review.md)

## 🔒 구조 변경 전 안전 원칙 (Safety Rules)

1. **상대 참조 무결성 검증**: 실제 폴더 및 파일 이동을 가하기 전, `yaongyaong_ai_studio` 엔진 전체 소스 상에서 기존의 `_company`, `00_Raw`, `40_템플릿` 등의 디렉토리를 참조하는 소스 라인을 전수 조사하여 오작동이 없도록 선제 조치합니다.
2. **역사적 장부 데이터 유실 절대 금지**: 그동안 자율학습으로 누적된 소중한 전역 의사결정 장부(`decisions.md`), 히스토리(`tracker.json`), 그리고 누적 태스크 스케일(`company_state.json`)의 내용이 훼손되거나 초기화되지 않도록 철저히 백업하고 병합 정책을 유지합니다.
3. **에이전트 고유 지기/기억 보존**: 에이전트 폴더 내의 핵심 자가 진화 정보인 `memory.md` 파일들은 단순 삭제 또는 덮어쓰기 대상에서 제외합니다.
4. **로케일 호환성 확보**: 향후 파일 이동/리네임 시 특수문자나 한글 폴더명(`40_템플릿`)은 다중 인프라 환경 호환성을 위해 반드시 영문명(`templates/` 등)으로 변형하여 인코딩 에러를 원천 차단합니다.
