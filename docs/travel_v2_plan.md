## 1. 목표

이 자료는 **실제 여행 가이드**로 쓴다. 이용자가 관광지를 고르면 갈지 말지, 어떻게 가는지, 언제 열고 얼마인지, 무엇을 조심할지를 한 번에 알 수 있어야 한다. 이후 단계에서 주변 음식점·카페·숙박·즐길거리까지 연결한다.

두 가지 원칙을 지킨다.

1. **확인한 것만 공개한다.** 모든 값은 공식·1차 출처와 확인일을 가진다. 모르면 비우지 말고 "확인 불가"와 이유를 쓴다.
2. **수집과 검증을 나눈다.** 수집은 Sonnet 5.5, 검증은 Opus 5.5가 독립적으로 한다. 검증을 통과한 값만 반영한다.

## 2. 근거: 지금 자료의 상태

|---|---|---|

| 파이프라인 시범(6곳, 137 claim) | 수집 claim 의 **6.6% 가 틀렸고** 검증에서 모두 수정. 정보량은 크게 늘어남 | 검증 단계는 필수 |
| 좌표 1차(526곳) | high 318, medium 73, low 65, none 70 | 74% 바로 사용, 나머지 검증 |

시범에서 확인된 제약도 있다.
- 공식 출처끼리 서로 다른 경우가 흔하다(경복궁 요금·시간, 롯데월드 날씨 기준).
- 오래된 공식 페이지가 있다(도톤보리 상점회 2015, 기요미즈데라 에티켓 2024-06).
- **충칭 공식 사이트는 이 실행 환경에서 접속되지 않는다.** 중국 신규 거점 일부는 공식 근거를 확보하지 못할 수 있다.
- 비용: 장소당 약 12만 토큰(수집 6.5만 + 검증 5.5만).

## 3. 데이터 모델 v2

나라마다 다른 필드를 [SCHEMA_V2.md](../travel-common/SCHEMA_V2.md)의 공통 구조로 맞춘다. 핵심은 세 가지다.

1. **claim 단위 근거**: 값마다 출처 URL, 확인일, 출처 갱신일, 검증 판정을 붙인다.
2. **가이드 필수 9항목**: 위치, 접근(교통·주차), 소요시간, 운영시간·휴무, 요금(무료는 "무료"로 명시), 예약(중국은 실명·여권), 결제, 한국어 지원, 주의. 항목마다 값 또는 확인 불가 이유를 둔다.
3. **충돌 기록**: 공식 출처끼리 다르면 채택한 값과 근거, 다른 값을 함께 남긴다. 채택은 ①관리 주체의 운영 안내 페이지 ②최신 공지 ③갱신일이 최근인 페이지 순으로 한다.

## 4. 생산 파이프라인

```
대상 선정 → 수집(Sonnet) → 독립 검증(Opus) → 병합·충돌 기록 → 빌드(catalog·md·index 자동 생성) → 릴리스 게이트
```

### 진행 방식: 큰 틀 우선, 1~2회차 고완성도, 이후 증분

반복되는 교차 수집을 여러 번 나눠 하면 비용이 계속 든다. 그래서 **틀(스키마·필수 항목·도구)을 먼저 고정**하고, 그 틀에 맞춰 1~2회차에서 완성도 높게 채운 뒤, 이후 버전은 바뀐 값과 새 장소만 다룬다.

- **검증은 전수**로 한다. 신뢰도가 사이트의 가치이므로 표본 검증으로 비용을 줄이지 않는다.
- 비용은 장소당 약 12만 토큰(시범 기준). 세션을 나눠 진행한다.
- 공식 출처로 채우지 못한 항목은 **보완 필요 작업표**(`travel-common/v2/worksheets/gaps.csv`)로 내보내 운영자가 채운다. 채운 값은 `owner_verified` 로 들어가고 사이트에 "운영자 확인"으로 표시된다.

## 6. 신규 장소와 접근 제약

- Tier A 초안의 신규 후보 49곳은 v2.0(20곳 안팎)과 v2.1로 나눠 추가한다. 일본 대도시 핵심(도톤보리, USJ, 스카이트리, 시부야, 후지산·가와구치코 등)을 먼저 넣는다.
- 공식 출처에 접속할 수 없는 곳(현재 충칭)은 `official_unreachable` 로 보류하고 공개하지 않는다. 다른 실행 환경(사용자 PC 브라우저 등)에서 수집할지 정한다.
- 공식 출처에 값이 없는 항목(롯데월드 정가, 기요미즈데라 일반 입장료 등)은 블로그 값으로 채우지 않는다. 운영사 문의나 현장 확인 등 별도 경로를 쓸지 정한다.

## 7. 이용자 기능 (v2 데이터로 가능한 것)

1. 지역 → 관광지 목록, 필터(소요시간·계절·카테고리·무료/유료·예약 필요)
2. 지도와 "가까운 곳" 정렬(좌표)
3. 방문 전 체크리스트: 예약·결제·여권(중국)·휴무
4. 반나절·하루 코스(소요시간 + 거리)
5. 주변 음식점·카페·숙박·즐길거리(v2.3 이후)
6. 신뢰도 표시: "공식 확인 N일 전", 확인 불가 항목 회색 표시, 공식 링크

## 8. 운영

- 운영값은 확인일 90일이 지나면 사이트에 재확인 표시, 180일이 지나면 비공개.
- 재검증은 릴리스 단위로 한다. 운영값이 바뀌기 쉬운 곳(테마파크, 계절 운영)은 우선한다.
- 모든 변경은 레코드별 이전값·새값·근거를 기록한다.

## 9. 확정 사항 (2026-10-11)

1. **진행 방식**: 큰 틀을 먼저 갖추고 1~2회차에서 완성도 있게 채운 뒤 증분 버전업. 검증은 전수.
2. **세션 분할**: v2.0 은 세션을 나눠 진행한다.
3. **정보가 부족한 관광지**(공식 출처 없음·접속 불가): 칸을 만들어 두고 운영자가 나중에 채운다(보완 작업표).
4. **공식 출처에 없는 값**: 3번과 같은 방식.
