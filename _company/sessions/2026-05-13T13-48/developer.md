# 📋 티스토리 연동 및 자동화 기술 검토 보고서

**수신:** CEO
**발신:** Developer (AI Agent)
**주제:** 구글 계정 기반 티스토리 API 연동 및 자동 포스팅 가능 여부 검토

---

### 1. 핵심 결론: **"기술적으로 가능하지만, '구글 계정' 자체의 권한이 아닌 '티스토리 API' 권한이 핵심입니다."**

구글 계정(Gmail 등)을 통해 티스토리에 로그인하는 것은 가능하지만, **자동화(Automation)**를 위해서는 구글 계정의 비밀번호를 사용하는 것이 아니라, **티스토리에서 발급하는 `Access Token`**이 반드시 필요합니다.

### 2. 상세 기술 검토

#### **A. 연동 메커니즘 (How it works)**
사용자가 구글 계정으로 티스토리에 로그인(OAuth 2.0)하더라도, 우리 시스템이 글을 쓰기 위해서는 다음의 단계가 필요합니다.
1.  **티스토리 API Open API 활용:** 티스토리에서 제공하는 공식 API를 사용해야 합니다.
2.  **Access Token 발급:** 사용자가 티스로기에 로그인한 후, 우리 서비스에 "글쓰기 권한"을 승인하는 과정이 필요합니다. 이 과정에서 `Access Token`이 생성됩니다.
3.  **구글 계정의 역할:** 구글 계정은 사용자를 식별(Identity)하는 용도로 사용되며, 실제 포스팅 작업은 이 `Access Token`을 통해 티스토리 서버에 명령을 내리는 방식으로 진행됩니다.

#### **B. 구현 가능한 자동화 범위**
*   **글쓰기 (Write):** 제목, 본문(HTML), 태그, 카테고리 지정 가능.
*   **이미지 업로드:** 포스팅에 필요한 이미지를 티스토리 서버로 직접 업로드 가능.
*   **관리:** 기존 포스팅 수정 및 삭제 가능.

#### **C. 기술적 허들 및 해결 방안**
| 구분 | 문제점 (Challenge) | 해결 방안 (Solution) |
| :--- | :---서버에서 사용자의 티스토리 계정에 접근할 권한이 없음 | **티스토리 OAuth 2.0 인증** 프로세스를 구현하여 사용자가 직접 권한을 승인하도록 설계 |
| **데이터 소스** | 구글 Docs나 Gmail의 내용을 티스토리로 가져와야 함 | **Google API (Docs/Gmail API)**를 연동하여 텍스트를 추출한 뒤, 이를 티스토리 API 규격(HTML)으로 변환하는 로직 필요 |
| **이미지 처리** | 구글 드라이브 내 이미지를 티스토리 본문에 넣기 어려움 | 구글 드라이브에서 이미지를 임시 다운로드 후, **티스토리 API의 이미지 업로드 엔드포인트**를 통해 재업로드 |

### 3. 향후 로드맵 제안 (Implementation Plan)

**[1단계] 기초 연동 (POC)**
*   티스토리 API App 등록 및 Client ID/Secret 확보.
*   수동으로 발급받은 Access Token을 사용하여 특정 텍스트를 티스토리에 포스팅하는 스크립트 작성.

**[2단계] 사용자 인증 자동화**
*   사용자가 "구글로 로그인 -> 티스토리 권한 승인" 프로세스를 거치면, 서버에 해당 사용자의 `Access Token`이 안전하게 저장되도록 DB 설계.

**[3단계] 콘텐츠 파이프라인 구축**
*   `Google Docs` (콘텐츠 원천) $\rightarrow$ `Python Script` (HTML 변환 및 이미지 추출) $\rightarrow$ `Tistory API` (자동 발행) 구조 완성.
