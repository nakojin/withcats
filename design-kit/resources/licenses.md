# 라이선스 빠른 판단표

목록의 자료를 상업 사이트(제휴 광고 수익 포함)에 넣기 전에 보는 표. **법률 자문이 아니다.** 최종 판단은 각 저장소의 `LICENSE` 파일로 한다. 라이선스는 바뀔 수 있다(예: Pico·Polaris 보관 처리, ApexCharts v5 전환).

## 한눈에

| 라이선스 | 상업 사용 | 수정 | 의무 | 판단 |
|---|---|---|---|---|
| **MIT** | O | O | 저작권·라이선스 문구 보존 | 그냥 써도 됨 |
| **ISC** | O | O | MIT 와 같음 (Lucide) | 그냥 써도 됨 |
| **BSD-2 / BSD-3** | O | O | 문구 보존. BSD-3 는 원작자 이름으로 홍보 금지 | 그냥 써도 됨 |
| **Apache-2.0** | O | O | 문구·NOTICE 보존, 수정 파일 표시. 특허 허여 포함 | 그냥 써도 됨 |
| **CC0 / Unlicense** | O | O | 없음 (퍼블릭 도메인) | 그냥 써도 됨 |
| **OFL-1.1** (폰트) | O | O | 폰트 파일 **단독 판매 금지**, 수정 시 이름 변경 | 웹폰트·이미지·인쇄물 모두 OK |
| **zlib** | O | O | 출처를 원작이라 속이지 말 것 | 그냥 써도 됨 |
| **MPL-2.0** | O | O | **그 파일을 수정**해 배포하면 그 파일만 공개 | 수정 없이 쓰면 부담 없음 (axe-core) |
| **LGPL** | O | O | 라이브러리를 수정하면 공개, 링크만 하면 자유 | 수정 금지 원칙으로 사용 |
| **GPL-2/3** | O | O | 배포하는 결합물 전체를 GPL 로 | 프론트 번들에 넣지 말 것. WordPress 테마는 원래 GPL 이라 예외 |
| **AGPL** | O | O | 네트워크 서비스로 제공해도 소스 공개 | 피한다 |

## 저작권은 라이선스와 별개

- 애니메이션 캐릭터·스크린샷·공식 일러스트는 **오픈소스 라이선스와 무관하게** 권리자 허락이 필요하다. UI 키트로 해결되지 않는다.
- 대안: 직접 만든 일러스트, 쿠팡 파트너스가 제공하는 상품 이미지(제휴 링크 안에서), 텍스트·타이포·색으로 만든 비주얼(표현형 레이어의 붓칠·잉크 튐이 그 용도).
