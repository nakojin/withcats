# UX·접근성 점검표

출시 전에 화면 단위로 확인한다. 괄호는 근거(WCAG 2.2 기준 번호, 또는 키트에서 이미 처리한 위치).

## 1. 구조
- [ ] 페이지마다 `<h1>` 하나, 제목 단계 건너뛰지 않기 (1.3.1)
- [ ] `<header> <nav> <main> <footer>` 랜드마크 사용, `<main>` 은 하나
- [ ] 첫 Tab 에 "본문 바로가기" 링크 (2.4.1)
- [ ] `<html lang="ko">` (3.1.1)
- [ ] 페이지 `<title>` 이 화면마다 다름: "화면명 | 사이트명" (2.4.2)

## 2. 터치·키보드
- [ ] 누를 수 있는 모든 것 최소 44×44px — `--tap` 토큰 (2.5.8)
- [ ] 마우스 없이 Tab·Enter·Space·Esc 로 전부 조작 가능 (2.1.1)
- [ ] 포커스 링이 보임 — `:focus-visible` 전역 처리됨 (`base.css`) (2.4.7)
- [ ] 포커스가 고정 헤더·하단 탭바에 가려지지 않음 — `scroll-padding` (2.4.11)
- [ ] 클릭 가능한 `<div>` 금지. 이동은 `<a href>`, 동작은 `<button>`
- [ ] 드래그로만 되는 기능에 버튼 대안 (2.5.7)

## 3. 색·대비
- [ ] 본문 글자 대비 4.5:1 이상, 큰 글자(24px+ 또는 19px 굵게) 3:1 (1.4.3)
- [ ] 아이콘·입력칸 테두리·포커스 링 3:1 (1.4.11)
- [ ] 색만으로 상태 구분 금지 — 아이콘·글자 함께 (1.4.1)
- [ ] 라이트·다크 둘 다 확인. 브랜드색 바꾸면 `--on-accent` 대비 재확인
- [ ] 확대 200% 와 가로 320px 에서 가로 스크롤 없음 (1.4.4, 1.4.10)

## 4. 폼
- [ ] 모든 입력에 보이는 `<label>`. placeholder 는 라벨이 아님 (3.3.2)
- [ ] 오류는 `aria-invalid="true"` + `aria-describedby` 로 오류 문장 연결 — `.kit-field__error` (3.3.1)
- [ ] 오류 문장은 "무엇이 틀렸고 어떻게 고치는지": "이메일에 @가 빠졌어요"
- [ ] `autocomplete`, `inputmode`, `type="email|tel"` 지정 (1.3.5)
- [ ] 제출 중 버튼 `aria-busy="true"` + 비활성 — 이중 제출 방지
- [ ] 같은 정보 두 번 묻지 않기 (3.3.7)

## 5. 피드백·상태
- [ ] 모든 목록에 **빈 상태**(`.kit-empty`): 이유 + 다음 행동 버튼
- [ ] 로딩 300ms 이상이면 **스켈레톤**(`.kit-skeleton`), 레이아웃 크기 미리 확보 (CLS)
- [ ] 오류 상태: 다시 시도 버튼, 입력값 유지
- [ ] 성공 알림은 토스트(`toast()`, `aria-live`), 되돌릴 수 있으면 "실행 취소" 제공
- [ ] 파괴적 동작(삭제)은 `is-danger` + 확인 시트

## 6. 오버레이
- [ ] 시트·모달은 `<dialog>.showModal()` — 포커스 가두기·Esc·배경 비활성 자동 (`sheet`)
- [ ] 닫으면 연 버튼으로 포커스 복귀 (네이티브 dialog 가 처리)
- [ ] 시트 높이 최대 90dvh, 내부만 스크롤
- [ ] 툴팁에만 중요한 정보 두지 않기 (터치에서 안 보임)

## 7. 모션
- [ ] `prefers-reduced-motion` 존중 — 토큰 지속시간 0 처리됨
- [ ] 5초 넘게 자동 재생되는 움직임은 정지 버튼 (2.2.2)
- [ ] 1초에 3번 넘게 번쩍이는 효과 금지 (2.3.1)

## 8. 이미지·미디어
- [ ] 의미 있는 이미지 `alt`, 장식 이미지 `alt=""`, 아이콘 `aria-hidden` (1.1.1)
- [ ] 아이콘만 있는 버튼은 `aria-label`
- [ ] `width`/`height` 또는 `aspect-ratio` 지정 → 레이아웃 흔들림 방지
- [ ] 첫 화면 밖 이미지는 `loading="lazy"`, 히어로는 `fetchpriority="high"`

## 9. 성능 (Core Web Vitals)
- [ ] LCP < 2.5s, INP < 200ms, CLS < 0.1 — Lighthouse 로 확인
- [ ] 폰트 `display=swap`, 본문 폰트는 다이나믹 서브셋(Pretendard)
- [ ] 아이콘은 스프라이트 하나 — 아이콘 폰트·개별 요청 금지
- [ ] 첫 화면에 필요 없는 JS 는 `type="module"` + 지연 로드

## 10. 제휴·수익 사이트 추가 항목
- [ ] 제휴 링크 근처, **첫 화면에 보이는 위치**에 대가성 문구 (공정위 추천·보증 심사지침)
- [ ] 제휴 링크 `rel="sponsored nofollow noopener"`, 새 창이면 아이콘으로 알림
- [ ] 가격은 "작성 시점 기준" 명시 — 실시간이 아니면 단정하지 않기
