## 이용 방법

- index.html: 파일을 브라우저로 열면 인터넷 없이 이름·도도부현·본문 검색과 권역 필터를 사용할 수 있습니다. 외부 라이브러리·지도·폰트는 없습니다. 공식 출처 링크 방문에는 인터넷이 필요합니다.
- catalog.json: 기계가 읽을 통합 자료. items 배열이 관광지 레코드입니다.
- places/: 관광지별 읽기용 Markdown.
- regions/: 권역별 목차.
- validation-report.json: 실제 수량, 47개 도도부현 수량, 필수필드·중복·날짜 검사와 검토사항.
- source-research/: 각 조사 묶음의 원본 JSON과 Markdown.

## 범위와 한계

공식 사이트 내용을 한국어 독자 안내로 요약했습니다. 직접 열람 여부는 조사 담당의 열람 기록에 근거하며, 모든 여행정보의 완전성 또는 미래 운영을 보증하지 않습니다. 웹검색 요약만 확인한 자료는 직접 열람 확인 수에 포함하지 않습니다. 가격·휴무·예약·교통·계절 일정은 방문 직전 공식 페이지에서 재확인하세요. 추천시기와 방문팁에는 자료를 바탕으로 한 편집적 조언이 포함될 수 있습니다.

단순 오프라인 HTML의 정적 구조는 검사했으며 실제 브라우저 화면 렌더링은 미검증입니다. 지도 좌표, 사진 사용권, 실시간 교통·예약·가격 데이터는 제공하지 않습니다. 외부 사이트에 게시하거나 GitHub에 업로드하지 않은 로컬 자료입니다.
